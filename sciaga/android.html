Szybka ściąga — aplikacje mobilne INF.04

Konstrukcje potrzebne w zadaniach mobilnych z analizowanych arkuszy (Android Studio · Java · XML). W nawiasach — arkusze, w których wystąpiły. Wszystko działa w projekcie Empty Views Activity, język Java.

Najważniejsze pułapki: backgroundTint zamiast background na przyciskach · setText("" + liczba), nigdy setText(liczba) · equals, nie == dla napisów · 0dp przy layout_weight · nazwy zasobów małymi literami · notifyDataSetChanged() po zmianie listy.

1. Szkielet

MainActivity.java
package com.example.egzamin;          // zostaw swoją nazwę pakietu

import android.os.Bundle;
import android.widget.*;                // lub pojedyncze importy (Alt+Enter)
import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {
    private int licznik = 0;            // stan = pola klasy
    private TextView tvWynik;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        tvWynik = findViewById(R.id.tvWynik);   // PO setContentView
    }
}
activity_main.xml — korzeń
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:id="@+id/main"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    android:background="#F5F5DC">
    <!-- kontrolki -->
</LinearLayout>

Jeżeli w onCreate zostały linie EdgeToEdge…/ViewCompat… — korzeń musi mieć android:id="@+id/main". Uwaga: ten kod nadpisuje padding korzenia (odstępy daj wtedy elementom wewnątrz).
