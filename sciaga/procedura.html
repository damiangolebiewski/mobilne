Procedura egzaminacyjna — część mobilna

Na podstawie poleceń z analizowanych arkuszy. Zawsze czytaj własne polecenie — nazwy folderów i zrzutów różnią się między sesjami (np. mobilna / mobilne, mobile1.png / mobilna.jpg).

Przed startem (2 min)

  1. Utwórz folder nazwany numerem zdającego, a w nim podfoldery z polecenia (np. konsola lub konsolowa, mobilna, dokumentacja lub testy).
  2. Rozpakuj archiwum z zasobami (hasło podane w arkuszu).
  3. Uruchom Android Studio i emulator (Device Manager) — emulator startuje długo, więc zrób to od razu.

Nowy projekt

File → New → New Project → Empty Views Activity → Name: dowolna (np. Mobilna), Language: Java, Minimum SDK: domyślne → Finish. Korzeń w activity_main.xml zamień na LinearLayout. Jeśli w onCreate są linie EdgeToEdge/ViewCompat — usuń je albo nadaj korzeniowi android:id="@+id/main".

Zrzuty ekranu

  • Obejmują cały ekran z paskiem zadań: widoczny emulator z aplikacją i otwarte środowisko z projektem.
  • Tyle zrzutów, ile interakcji (stan początkowy + każda czynność z polecenia).
  • Gdy aplikacja się nie kompiluje: zrzut z oknem błędów (Build) i środowiskiem.
  • Windows: PrtSc → Paint (Ctrl+V) → Zapisz jako PNG/JPG z nazwą z polecenia; lub Win+Shift+S.

Pakowanie i kopiowanie

  1. File → Close Project (zamyka pliki projektu).
  2. Eksplorator: C:\Users\<konto>\AndroidStudioProjects\<Projekt> → prawy przycisk → Wyślij do → Folder skompresowany (zip) → nazwa mobilna.zip → przenieś do folderu mobilna.
  3. Skopiuj do folderu mobilna:
    • app\src\main\res\layout\activity_main.xml (i inne zmieniane układy, np. list_item.xml),
    • app\src\main\java\com\example\…\MainActivity.java.

Dokumentacja (gdy wymagana)

Plik egzamin (edytor tekstu pakietu biurowego) lub srodowisko.txt (Arkusz_07) zawiera:

  • nazwę systemu operacyjnego (np. Windows 10 Pro),
  • nazwy środowisk programistycznych (np. Android Studio + wersja z Help → About; środowisko części konsolowej),
  • nazwy języków programowania (Java, XML; + język części konsolowej),
  • nazwę emulatora (np. Pixel 5 API 30 — z Device Manager),
  • podpisane zrzuty ekranu (jeśli polecenie tego wymaga) i opcjonalny komentarz.
