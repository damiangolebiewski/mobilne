Blok 12. Debugowanie i procedura egzaminacyjna

Faza III — tryb egzaminacyjny W trakcie

Naprawiasz aplikacje z typowymi błędami (kompilacja, awaria, zła logika, zły wygląd), czytasz Logcat i ćwiczysz pełną procedurę oddania pracy. Na końcu — zadanie egzaminacyjne na czas (60 min).

1. Cel

Po wykonaniu tego bloku będziesz potrafił:

  • rozróżnić błąd budowania, awarię w czasie działania, błąd logiki i błąd wyglądu,
  • odczytać w oknie Build i w Logcat nazwę błędu, plik i numer linii,
  • naprawić 10 najczęstszych błędów z aplikacji egzaminacyjnych,
  • wykonać komplet czynności oddania pracy: zrzuty, mobilna.zip, kopie plików, opis środowiska,
  • zmieścić się z zadaniem mobilnym w 60 minutach.

Procedura oddania (wg arkuszy)

  1. Folder z numerem zdającego, w nim podfoldery z polecenia (np. konsola, mobilna, dokumentacja).
  2. Uruchom aplikację w emulatorze. Zrzuty całego ekranu z paskiem zadań (emulator + otwarte Android Studio): stan początkowy i każda interakcja. Nazwy z polecenia (mobile1.png, mobile2.png … lub mobilna.jpg). Skrót Windows: Win+Shift+S (lub PrtSc) → wklej do Painta → zapisz.
  3. Gdy aplikacja się nie kompiluje: zrzut z oknem błędów i otwartym środowiskiem — to też jest punktowane.
  4. File → Close Project (albo zamknij Android Studio), spakuj cały folder projektu do mobilna.zip.
  5. Skopiuj do folderu mobilna: app\src\main\res\layout\activity_main.xml i app\src\main\java\…\MainActivity.java (+ inne zmieniane pliki, np. list_item.xml).
  6. Opis środowiska — tam, gdzie wymaga polecenie (egzamin.docx lub srodowisko.txt): system operacyjny, Android Studio (wersja), język Java, nazwa emulatora (np. Pixel 5 API 30).

4. Mikroćwiczenia

Ćwiczenie 12.1 — Błąd budowania: nazwa zasobu

Po wklejeniu obrazów Build pokazuje: '-' is not a valid file-based resource name character dla kosc-1.png. Co zrobić?

Sprawdź odpowiedź

Zmień nazwę pliku (Shift+F6) na kosc1.png / kosc_1.png i popraw odwołania (R.drawable.kosc1).

Ćwiczenie 12.2 — Awaria przy starcie

Szablon zawiera ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), …). Uczeń zamienił ConstraintLayout na LinearLayout i aplikacja zamyka się od razu po uruchomieniu (NullPointerException). Dwie możliwe naprawy?

Sprawdź odpowiedź

Dodaj android:id="@+id/main" do nowego korzenia albo usuń linie EdgeToEdge/ViewCompat z onCreate (wersja kursowa).

Ćwiczenie 12.3 — cannot find symbol

error: cannot find symbol symbol: variable btnZatwierdz location: class id. Co jest źle?

Sprawdź odpowiedź

W XML nie ma elementu z android:id="@+id/btnZatwierdz" (literówka, inna nazwa, brak id). Porównaj id w XML i w findViewById.

Ćwiczenie 12.4 — Hasła „różne”

Oba pola zawierają „abc123”, a aplikacja wyświetla „Hasła się różnią”. W kodzie: if (haslo != haslo2). Popraw.

Sprawdź odpowiedź

if (!haslo.equals(haslo2)).

Ćwiczenie 12.5 — Kolor przycisku

W XML przycisku jest android:background="#D2691E", a w emulatorze przycisk jest fioletowy. Popraw.

Sprawdź odpowiedź

Zamień na android:backgroundTint="#D2691E" (motyw Material 3 ignoruje background na przyciskach).

Ćwiczenie 12.6 — Kość z zerem

int oczka = r.nextInt(6); ivKosc.setImageResource(kosci[oczka]); — czasem pokazuje złą ściankę, a punkty się nie zgadzają. Co jest nie tak?

Sprawdź odpowiedź

Oczka są 0..5 zamiast 1..6. Poprawnie: int oczka = r.nextInt(6) + 1; i obraz kosci[oczka - 1].

Ćwiczenie 12.7 — Równe przyciski

Trzy przyciski mają layout_weight="1", ale różną szerokość. Co sprawdzić?

Sprawdź odpowiedź

Szerokość musi być layout_width="0dp". Przy wrap_content waga dzieli tylko wolne miejsce, a nie całą szerokość.

Ćwiczenie 12.8 — Niewidoczny separator

Lista ma android:divider="#DC143C", a separatora nie widać. Dlaczego?

Sprawdź odpowiedź

Kolor ustawiony jako separator nie ma własnej wysokości. Dodaj android:dividerHeight="2dp" (Arkusz_05: „separator jest widoczny, np. poprzez ustawienie wysokości separatora”).

⏱ ok. 30 min

MainActivity.java (z błędami)
package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.EditText;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private int kroki = 0;
    private int cel = 1000;
    private TextView tvKroki, tvStatus;
    private EditText etCel;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        tvKroki = findViewById(R.id.tvKroki);
        tvStatus = findViewById(R.id.tvStatus);
        etCel = findViewById(R.id.etCel);
        Button btnDodaj = findViewById(R.id.btnPlus);
        Button btnReset = findViewById(R.id.btnReset);
        Button btnUstawCel = findViewById(R.id.btnUstawCel);

        btnDodaj.setOnClickListener(v -> {
            kroki += 100;
            pokaz();
        });

        btnReset.setOnClickListener(v -> {
            kroki = 0;
        });

        btnUstawCel.setOnClickListener(v -> {
            cel = Integer.parseInt(etCel.getText().toString().trim());
            pokaz();
        });
    }

    private void pokaz() {
        tvKroki.setText(kroki);
        if (kroki >= cel) {
            tvStatus.setText("Cel osiągnięty!");
        } else {
            tvStatus.setText("Do celu: " + (cel - kroki));
        }
    }
}

Poziom 1 — kierunek

Zacznij od okna Build — dopóki projekt się nie buduje, nie zobaczysz pozostałych błędów. Dwa błędy budowania: jeden w XML, jeden w Javie.

Poziom 2 — konkretna wskazówka

Budowanie: tvStatus bez layout_height; R.id.btnPlus nie istnieje. Awarie: setText(kroki), parseInt z pustego pola. Logika: RESET nie odświeża. Wygląd: wagi z wrap_content.

Poziom 3 — pseudokod / struktura
Tekst
1. XML tvStatus  → dodaj android:layout_height="wrap_content"
2. XML przyciski → layout_width="0dp"
3. Java          → findViewById(R.id.btnDodaj)
4. Java pokaz()  → setText("Kroki: " + kroki)
5. Java cel      → try { parseInt … } catch (NumberFormatException e) { Toast }
6. Java reset    → po kroki = 0 wywołaj pokaz()

});

package com.example.egzamin;

import android.os.Bundle;
import android.view.View;
import android.widget.ArrayAdapter;
import android.widget.Button;
import android.widget.EditText;
import android.widget.ListView;
import android.widget.TextView;
import android.widget.Toast;

import java.util.Arrays;
import java.util.List;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private final List<String> zadania = Arrays.asList("Projekt z INF.04", "Zakupy");
    private ArrayAdapter<String> adapter;
    private EditText etZadanie;
    private TextView tvLiczba;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        etZadanie = findViewById(R.id.etZadanie);
        tvLiczba = findViewById(R.id.tvLiczba);
        ListView lvZadania = findViewById(R.id.lvZadania);
        Button btnDodaj = findViewById(R.id.btnDodaj);

        adapter = new ArrayAdapter<>(this, android.R.layout.simple_list_item_1, zadania);
        lvZadania.setAdapter(adapter);

        btnDodaj.setOnClickListener(new View.OnClickListener() {
            @Override
            public void onClick(View v) {
                String zadanie = etZadanie.getText().toString().trim();
                if (zadanie.isEmpty()) {
                    Toast.makeText(this, "Wpisz zadanie", Toast.LENGTH_SHORT).show();
                    return;
                }
                tvLiczba.setText("Zadań: " + zadania.size());
                zadania.add(zadanie);
                etZadanie.setText("");
            }
        });
    }
}

Elementy aplikacji:

  • Napis „Ankieta — stołówka”.
  • Napis „Jak oceniasz dzisiejszy obiad?”.
  • Trzy pola radio w jednym rzędzie: „Źle”, „Średnio”, „Dobrze”; w stanie początkowym żadne nie jest zaznaczone.
  • Obraz oceny — w stanie początkowym niewidoczny, ale zajmujący miejsce.
  • Rząd: napis „Wielkość porcji:”, suwak, napis z wartością (początkowo „3”). Suwak pozwala wybrać wartość od 1 do 5.
  • Pole edycyjne z podpowiedzią „Komentarz (opcjonalnie)”.
  • Przycisk „WYŚLIJ”.
  • Napis „Głosów: 0 | źle: 0, średnio: 0, dobrze: 0” oraz napis „Średnia porcja: –”.
  • Napis „Autor: ”, dalej numer zdającego.

Działanie aplikacji:

  • Zaznaczenie pola radio od razu wyświetla odpowiedni obraz: buzka_zla, buzka_neutralna, buzka_dobra.
  • Przesuwanie suwaka zmienia napis z wartością porcji (liczba całkowita 1–5).
  • Po wybraniu „WYŚLIJ”:
    • gdy nie zaznaczono oceny — komunikat Toast „Zaznacz ocenę”, nic więcej się nie zmienia;
    • w przeciwnym razie głos jest zliczany, napis głosów i napis „Średnia porcja: x” (jedno miejsce po przecinku, średnia ze wszystkich oddanych głosów) są aktualizowane, wyświetla się Toast „Dziękujemy za głos” albo — gdy wpisano komentarz — „Dziękujemy! Komentarz: <treść>”;
    • formularz jest przygotowany dla następnej osoby: brak zaznaczenia (obraz niewidoczny), porcja 3, puste pole komentarza.

Założenia aplikacji:

  • Interfejs w XML; rozkład liniowy pionowy z zagnieżdżonymi rozkładami poziomymi (pola radio, porcja).
  • Tło strony #E8EAF6; tytuł: tło #283593, biała czcionka, największa, marginesy wewnętrzne 10; pytanie pogrubione.
  • Pola radio równej szerokości; obraz wysokości 120; przycisk wyśrodkowany, tło #283593, biała czcionka; średnia pogrubiona.

package com.example.egzamin;

import android.os.Bundle;
import android.view.View;
import android.widget.Button;
import android.widget.EditText;
import android.widget.ImageView;
import android.widget.RadioGroup;
import android.widget.SeekBar;
import android.widget.TextView;
import android.widget.Toast;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private static final int PORCJA_START = 2;   // progress 2 = porcja 3 (zakres 1..5)

    private final int[] glosy = new int[3];       // 0 źle, 1 średnio, 2 dobrze
    private int sumaPorcji = 0;

    private RadioGroup rgOcena;
    private ImageView ivBuzka;
    private SeekBar sbPorcja;
    private TextView tvPorcja, tvWyniki, tvSrednia;
    private EditText etKomentarz;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        rgOcena = findViewById(R.id.rgOcena);
        ivBuzka = findViewById(R.id.ivBuzka);
        sbPorcja = findViewById(R.id.sbPorcja);
        tvPorcja = findViewById(R.id.tvPorcja);
        tvWyniki = findViewById(R.id.tvWyniki);
        tvSrednia = findViewById(R.id.tvSrednia);
        etKomentarz = findViewById(R.id.etKomentarz);
        Button btnWyslij = findViewById(R.id.btnWyslij);

        rgOcena.setOnCheckedChangeListener((group, checkedId) -> {
            int indeks = indeksOceny(checkedId);
            if (indeks == -1) {                       // clearCheck() też wywołuje to zdarzenie
                ivBuzka.setVisibility(View.INVISIBLE);
                return;
            }
            int[] buzki = {R.drawable.buzka_zla, R.drawable.buzka_neutralna, R.drawable.buzka_dobra};
            ivBuzka.setImageResource(buzki[indeks]);
            ivBuzka.setVisibility(View.VISIBLE);
        });

        sbPorcja.setOnSeekBarChangeListener(new SeekBar.OnSeekBarChangeListener() {
            @Override
            public void onProgressChanged(SeekBar seekBar, int progress, boolean fromUser) {
                tvPorcja.setText(String.valueOf(progress + 1));
            }

            @Override
            public void onStartTrackingTouch(SeekBar seekBar) {
            }

            @Override
            public void onStopTrackingTouch(SeekBar seekBar) {
            }
        });

        btnWyslij.setOnClickListener(v -> wyslij());
    }

    private int indeksOceny(int idPola) {
        if (idPola == R.id.rbZle) {
            return 0;
        } else if (idPola == R.id.rbSrednio) {
            return 1;
        } else if (idPola == R.id.rbDobrze) {
            return 2;
        }
        return -1;
    }

    private void wyslij() {
        int indeks = indeksOceny(rgOcena.getCheckedRadioButtonId());
        if (indeks == -1) {
            Toast.makeText(this, "Zaznacz ocenę", Toast.LENGTH_SHORT).show();
            return;
        }
        glosy[indeks]++;
        sumaPorcji += sbPorcja.getProgress() + 1;
        int wszystkie = glosy[0] + glosy[1] + glosy[2];

        tvWyniki.setText("Głosów: " + wszystkie + " | źle: " + glosy[0] + ", średnio: " + glosy[1] + ", dobrze: " + glosy[2]);
        tvSrednia.setText(String.format("Średnia porcja: %.1f", (double) sumaPorcji / wszystkie));

        String komentarz = etKomentarz.getText().toString().trim();
        String podziekowanie = komentarz.isEmpty() ? "Dziękujemy za głos" : "Dziękujemy! Komentarz: " + komentarz;
        Toast.makeText(this, podziekowanie, Toast.LENGTH_SHORT).show();

        // przygotowanie formularza dla następnej osoby
        rgOcena.clearCheck();
        sbPorcja.setProgress(PORCJA_START);
        etKomentarz.setText("");
    }
}
