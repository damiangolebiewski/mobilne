Blok 11. Formularz złożony: wiele kontrolek i zbiorczy wynik

Faza III — tryb egzaminacyjny W trakcie

Łączysz listę, suwak zależny od wyboru, pole czasu, pola radio i pola wyboru w jednym formularzu i składasz z nich wynik w napisie lub oknie dialogowym. Pierwszy blok trybu egzaminacyjnego: podpowiedzi są, ale ukryte.

1. Cel

Po wykonaniu tego bloku będziesz potrafił:

  • odczytać wybór z RadioGroup (getCheckedRadioButtonId) i stan CheckBox (isChecked),
  • użyć pola czasu (TimePicker w trybie 24 h) i sformatować godzinę „HH:MM”,
  • zmieniać maksimum suwaka po wybraniu elementu listy i pilnować spójności napisu obok,
  • złożyć wynik z wielu pól (oddzielonych przecinkami) i pokazać go w TextView lub AlertDialog,
  • samodzielnie rozplanować zadanie według workflow egzaminacyjnego.

Powiązanie z arkuszami: Arkusz_10 (lista → maksimum suwaka, wiek obok suwaka, pole czasu 16:00, wynik po przecinkach w napisie albo oknie komunikatu); pola radio i pola wyboru z desktopowych Arkuszy 04, 06, 09 — kompetencja C, ćwiczona pomocniczo.

2. Krótkie przypomnienie

Pola radio — jeden wybór z grupy

XML
<RadioGroup android:id="@+id/rgRodzaj" android:layout_width="match_parent"
    android:layout_height="wrap_content" android:orientation="horizontal">
    <RadioButton android:id="@+id/rbNormalny" android:layout_width="wrap_content"
        android:layout_height="wrap_content" android:text="Normalny" android:checked="true" />
    <RadioButton android:id="@+id/rbUlgowy" android:layout_width="wrap_content"
        android:layout_height="wrap_content" android:text="Ulgowy" />
</RadioGroup>
Java
int id = rgRodzaj.getCheckedRadioButtonId();   // -1, gdy nic nie zaznaczono
if (id == R.id.rbUlgowy) { … }

RadioGroup sam pilnuje, aby zaznaczone było tylko jedno pole („w grupie może być jednocześnie zaznaczone jedno pole”).

Pole wyboru

Java
if (cbTort.isChecked()) { cena += 50; }

Pole czasu (Arkusz_10: „pole dedykowane do zapisu czasu z wartością początkową 16:00”)

XML
<TimePicker android:id="@+id/tpGodzina" android:layout_width="wrap_content"
    android:layout_height="wrap_content" android:timePickerMode="spinner" />
Java
tpGodzina.setIs24HourView(true);
tpGodzina.setHour(16);
tpGodzina.setMinute(0);
...
String godzina = String.format("%02d:%02d", tpGodzina.getHour(), tpGodzina.getMinute());

Prostsza alternatywa: EditText z inputType="time" i tekstem „16:00”.

Okno komunikatu

Java
new AlertDialog.Builder(this)            // import androidx.appcompat.app.AlertDialog
        .setTitle("Zapisana wizyta")
        .setMessage(tresc)
        .setPositiveButton("OK", null)   // null = tylko zamknij okno
        .show();

Wynik z wielu pól, „rozdzielone przecinkiem”

Java
String tresc = imie + ", " + gatunek + ", " + wiek + ", " + cel + ", " + godzina;

Wybór z listy zapamiętuj w polu klasy (np. int wybrany = -1). Przy zatwierdzaniu sprawdź -1, zanim użyjesz go jako indeksu.

package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.CheckBox;
import android.widget.RadioGroup;
import android.widget.TextView;
import android.widget.TimePicker;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        RadioGroup rgRozmiar = findViewById(R.id.rgRozmiar);
        CheckBox cbSer = findViewById(R.id.cbSer);
        TimePicker tpDostawa = findViewById(R.id.tpDostawa);
        TextView tvPodsumowanie = findViewById(R.id.tvPodsumowanie);
        Button btnPodsumuj = findViewById(R.id.btnPodsumuj);

        tpDostawa.setIs24HourView(true);
        tpDostawa.setHour(18);
        tpDostawa.setMinute(0);

        btnPodsumuj.setOnClickListener(v -> {
            // które pole radio jest zaznaczone? -> porównujemy identyfikatory
            int zaznaczone = rgRozmiar.getCheckedRadioButtonId();
            String rozmiar;
            int cena;
            if (zaznaczone == R.id.rbMala) {
                rozmiar = "mała";
                cena = 20;
            } else if (zaznaczone == R.id.rbSrednia) {
                rozmiar = "średnia";
                cena = 28;
            } else {
                rozmiar = "duża";
                cena = 36;
            }
            if (cbSer.isChecked()) {
                cena += 4;
            }
            String godzina = String.format("%02d:%02d", tpDostawa.getHour(), tpDostawa.getMinute());
            tvPodsumowanie.setText("Pizza " + rozmiar + (cbSer.isChecked() ? " z serem" : "")
                    + ", dostawa " + godzina + ", do zapłaty " + cena + " zł");
        });
    }
}

4. Mikroćwiczenia

Ćwiczenie 11.1 — Które radio?

Grupa rgStrefa z polami rbStrefaA (5 zł/h) i rbStrefaB (3 zł/h). Zapisz w jednej linii stawkę zależną od zaznaczenia.

Sprawdź odpowiedź

int stawka = rgStrefa.getCheckedRadioButtonId() == R.id.rbStrefaA ? 5 : 3;

Ćwiczenie 11.2 — Format godziny

Godzina 9, minuta 5. Co wyświetli tp.getHour() + ":" + tp.getMinute(), a co String.format("%02d:%02d", …)?

Sprawdź odpowiedź

Pierwsze: „9:5”, drugie: „09:05”.

Ćwiczenie 11.3 — Lista → maksimum

Lista sal „Główna”, „Ogród”, „Loża VIP”, maksymalnie 8, 6, 4 osoby. Suwak pokazuje liczbę osób 1..max. Napisz obsługę kliknięcia listy.

Sprawdź odpowiedź
Java
lvSale.setOnItemClickListener((parent, view, position, id) -> {
    wybranaSala = position;
    sbOsoby.setMax(maksOsob[position] - 1);
    tvOsoby.setText(String.valueOf(sbOsoby.getProgress() + 1));
});

Ćwiczenie 11.4 — Okno czy napis?

Arkusz_10 pozwala pokazać wynik „w postaci napisu pod przyciskiem albo w postaci okna z komunikatem”. Co jest szybsze do napisania na egzaminie, a co trzeba zrobić w obu przypadkach?

Sprawdź odpowiedź

Napis (setText) jest najszybszy. W obu przypadkach trzeba złożyć ten sam tekst z wartościami oddzielonymi przecinkami — zbuduj go raz w zmiennej tresc.

5. Zadanie prowadzone

Bilety do kina

⏱ ok. 35 min

Wybór filmu z listy ustala maksymalną liczbę biletów (wolne miejsca), pola radio — rodzaj biletu. Potwierdzenie w oknie dialogowym.

Działanie:

  • Filmy i wolne miejsca: sala 1 — 4, sala 2 — 10, sala 3 — 6. Kliknięcie filmu: „Film: <nazwa>”, suwak biletów 1..wolne miejsca.
  • Suwak: napis obok pokazuje liczbę biletów (od 1).
  • KUP BILETY: gdy nie wybrano filmu — Toast „Wybierz film z listy”; inaczej AlertDialog „Twoje bilety” z treścią „<film>, <n> szt., <normalny/ulgowy>, razem <kwota> zł” (normalny 25 zł, ulgowy 18 zł).

Kroki:

  1. XML wg makiety (lista wrap_content, rząd z suwakiem, RadioGroup poziomy z zaznaczonym „Normalny”).
  2. Pola klasy: wybranyFilm = -1, tablice filmów i miejsc.
  3. Obsługa listy, suwaka, przycisku; metoda liczbaBiletow().

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Najpierw lista i napis „Film: …”, potem suwak z przesunięciem o 1, na końcu przycisk i okno.

Poziom 2 — konkretna wskazówka

Maksimum: sbBilety.setMax(wolneMiejsca[position] - 1);. Ulgowy: rgRodzaj.getCheckedRadioButtonId() == R.id.rbUlgowy.

Poziom 3 — pseudokod / struktura
Tekst
klik filmu(p): wybranyFilm ← p; napis filmu; setMax(miejsca[p] − 1); napis liczby
suwak: napis liczby ← progress + 1
KUP: jeśli wybranyFilm == −1 → Toast; koniec
     cena ← ulgowy ? 18 : 25; razem ← cena · liczba
     AlertDialog z treścią
Poziom 4 — fragment implementacji
Java
new AlertDialog.Builder(this)
        .setTitle("Twoje bilety")
        .setMessage(tresc)
        .setPositiveButton("OK", null)
        .show();

package com.example.egzamin;

import android.os.Bundle;
import android.widget.ArrayAdapter;
import android.widget.Button;
import android.widget.ListView;
import android.widget.RadioGroup;
import android.widget.SeekBar;
import android.widget.TextView;
import android.widget.Toast;

import androidx.appcompat.app.AlertDialog;
import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private final String[] filmy = {"Kosmiczna podróż (sala 1)", "Leśna przygoda (sala 2)", "Szybcy kurierzy (sala 3)"};
    private final int[] wolneMiejsca = {4, 10, 6};
    private int wybranyFilm = -1;   // -1 = nic nie wybrano

    private SeekBar sbBilety;
    private TextView tvFilm, tvBilety;
    private RadioGroup rgRodzaj;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        ListView lvFilmy = findViewById(R.id.lvFilmy);
        sbBilety = findViewById(R.id.sbBilety);
        tvFilm = findViewById(R.id.tvFilm);
        tvBilety = findViewById(R.id.tvBilety);
        rgRodzaj = findViewById(R.id.rgRodzaj);
        Button btnKup = findViewById(R.id.btnKup);

        lvFilmy.setAdapter(new ArrayAdapter<>(this, android.R.layout.simple_list_item_1, filmy));

        lvFilmy.setOnItemClickListener((parent, view, position, id) -> {
            wybranyFilm = position;
            tvFilm.setText("Film: " + filmy[position]);
            sbBilety.setMax(wolneMiejsca[position] - 1);    // zakres 1..wolne miejsca
            tvBilety.setText(String.valueOf(liczbaBiletow()));
        });

        sbBilety.setOnSeekBarChangeListener(new SeekBar.OnSeekBarChangeListener() {
            @Override
            public void onProgressChanged(SeekBar seekBar, int progress, boolean fromUser) {
                tvBilety.setText(String.valueOf(liczbaBiletow()));
            }

            @Override
            public void onStartTrackingTouch(SeekBar seekBar) {
            }

            @Override
            public void onStopTrackingTouch(SeekBar seekBar) {
            }
        });

        btnKup.setOnClickListener(v -> kup());
    }

    private int liczbaBiletow() {
        return sbBilety.getProgress() + 1;
    }

    private void kup() {
        if (wybranyFilm == -1) {
            Toast.makeText(this, "Wybierz film z listy", Toast.LENGTH_SHORT).show();
            return;
        }
        boolean ulgowy = rgRodzaj.getCheckedRadioButtonId() == R.id.rbUlgowy;
        int cena = ulgowy ? 18 : 25;
        int razem = cena * liczbaBiletow();
        String tresc = filmy[wybranyFilm] + ", " + liczbaBiletow() + " szt., "
                + (ulgowy ? "ulgowy" : "normalny") + ", razem " + razem + " zł";
        new AlertDialog.Builder(this)
                .setTitle("Twoje bilety")
                .setMessage(tresc)
                .setPositiveButton("OK", null)
                .show();
    }
}

6. Zadanie samodzielne

Wypożyczalnia rowerów

⏱ ok. 40 min

Formularz z sześcioma rodzajami kontrolek. Tylko opis i makieta — zaplanuj rozwiązanie sam.

  • Pole „Imię i nazwisko”; grupa radio: Miejski 10 zł/h (domyślnie), Górski 15 zł/h, Elektryczny 25 zł/h.
  • Suwak godzin 1..8 z napisem „<n> h”.
  • Pola wyboru: Kask +5 zł, Koszyk +3 zł (dopłaty jednorazowe).
  • TimePicker 24 h, start 10:00.
  • PODSUMUJ: przy pustym nazwisku „Podaj imię i nazwisko”, inaczej „<imię>, rower <typ>[ + kask][ + koszyk], <n> h od <GG:MM>, koszt <kwota> zł”.
  • Koszt = stawka · godziny + dopłaty.

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Rozbij podsumuj() na etapy: walidacja → godziny → rower i stawka → dodatki → godzina startu → tekst.

Poziom 2 — konkretna wskazówka

Dodatki zbieraj w zmiennej String dodatki = ""; i dopisuj " + kask", " + koszyk".

Poziom 3 — pseudokod / struktura
Tekst
podsumuj():
    imię puste → komunikat; koniec
    godziny ← progress + 1
    (rower, stawka) ← wg zaznaczonego radio
    koszt ← stawka · godziny; dodatki ← ""
    kask → koszt += 5, dodatki += " + kask"; koszyk → +3, " + koszyk"
    start ← format(HH:MM); napis wyniku
Poziom 4 — fragment implementacji
Java
int wybrany = rgRower.getCheckedRadioButtonId();

    rower = "górski"; stawka = 15;
} else if (wybrany == R.id.rbElektryczny) {
    rower = "elektryczny"; stawka = 25;
} else {
    rower = "miejski"; stawka = 10;
}

    private TextView tvGodziny, tvPodsumowanie;
    private CheckBox cbKask, cbKoszyk;
    private TimePicker tpStart;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        etImie = findViewById(R.id.etImie);
        rgRower = findViewById(R.id.rgRower);
        sbGodziny = findViewById(R.id.sbGodziny);
        tvGodziny = findViewById(R.id.tvGodziny);
        tvPodsumowanie = findViewById(R.id.tvPodsumowanie);
        cbKask = findViewById(R.id.cbKask);
        cbKoszyk = findViewById(R.id.cbKoszyk);
        tpStart = findViewById(R.id.tpStart);
        Button btnPodsumuj = findViewById(R.id.btnPodsumuj);

        tpStart.setIs24HourView(true);
        tpStart.setHour(10);
        tpStart.setMinute(0);

        sbGodziny.setOnSeekBarChangeListener(new SeekBar.OnSeekBarChangeListener() {
            @Override
            public void onProgressChanged(SeekBar seekBar, int progress, boolean fromUser) {
                tvGodziny.setText((progress + 1) + " h");
            }

            @Override
            public void onStartTrackingTouch(SeekBar seekBar) {
            }

            @Override
            public void onStopTrackingTouch(SeekBar seekBar) {
            }
        });

        btnPodsumuj.setOnClickListener(v -> podsumuj());
    }

    private void podsumuj() {
        String imie = etImie.getText().toString().trim();
        if (imie.isEmpty()) {
            tvPodsumowanie.setText("Podaj imię i nazwisko");
            return;
        }
        int godziny = sbGodziny.getProgress() + 1;
        int wybrany = rgRower.getCheckedRadioButtonId();
        String rower;
        int stawka;
        if (wybrany == R.id.rbGorski) {
            rower = "górski";
            stawka = 15;
        } else if (wybrany == R.id.rbElektryczny) {
            rower = "elektryczny";
            stawka = 25;
        } else {
            rower = "miejski";
            stawka = 10;
        }
        int koszt = stawka * godziny;
        String dodatki = "";
        if (cbKask.isChecked()) {
            koszt += 5;
            dodatki += " + kask";
        }
        if (cbKoszyk.isChecked()) {
            koszt += 3;
            dodatki += " + koszyk";
        }
        String start = String.format("%02d:%02d", tpStart.getHour(), tpStart.getMinute());
        tvPodsumowanie.setText(imie + ", rower " + rower + dodatki + ", " + godziny + " h od " + start + ", koszt " + koszt + " zł");
    }
}

package com.example.egzamin;

import android.os.Bundle;
import android.widget.ArrayAdapter;
import android.widget.Button;
import android.widget.CheckBox;
import android.widget.EditText;
import android.widget.ListView;
import android.widget.SeekBar;
import android.widget.TextView;
import android.widget.TimePicker;

import androidx.appcompat.app.AlertDialog;
import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private final String[] sale = {"Główna", "Ogród", "Loża VIP"};
    private final int[] maksOsob = {8, 6, 4};
    private int wybranaSala = -1;

    private EditText etNazwisko;
    private SeekBar sbOsoby;
    private TextView tvOsoby, tvPodsumowanie;
    private TimePicker tpGodzina;
    private CheckBox cbTort;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        etNazwisko = findViewById(R.id.etNazwisko);
        ListView lvSale = findViewById(R.id.lvSale);
        sbOsoby = findViewById(R.id.sbOsoby);
        tvOsoby = findViewById(R.id.tvOsoby);
        tvPodsumowanie = findViewById(R.id.tvPodsumowanie);
        tpGodzina = findViewById(R.id.tpGodzina);
        cbTort = findViewById(R.id.cbTort);
        Button btnZarezerwuj = findViewById(R.id.btnZarezerwuj);

        lvSale.setAdapter(new ArrayAdapter<>(this, android.R.layout.simple_list_item_1, sale));
        tpGodzina.setIs24HourView(true);
        tpGodzina.setHour(18);
        tpGodzina.setMinute(0);

        lvSale.setOnItemClickListener((parent, view, position, id) -> {
            wybranaSala = position;
            sbOsoby.setMax(maksOsob[position] - 1);   // SeekBar sam obetnie za dużą wartość
            tvOsoby.setText(String.valueOf(liczbaOsob()));
        });

        sbOsoby.setOnSeekBarChangeListener(new SeekBar.OnSeekBarChangeListener() {
            @Override
            public void onProgressChanged(SeekBar seekBar, int progress, boolean fromUser) {
                tvOsoby.setText(String.valueOf(progress + 1));
            }

            @Override
            public void onStartTrackingTouch(SeekBar seekBar) {
            }

            @Override
            public void onStopTrackingTouch(SeekBar seekBar) {
            }
        });

        btnZarezerwuj.setOnClickListener(v -> zarezerwuj());
    }

    private int liczbaOsob() {
        return sbOsoby.getProgress() + 1;
    }

    private void zarezerwuj() {
        if (wybranaSala == -1) {
            tvPodsumowanie.setText("Wybierz salę");
            return;
        }
        String godzina = String.format("%02d:%02d", tpGodzina.getHour(), tpGodzina.getMinute());
        String tresc = etNazwisko.getText().toString().trim() + ", "
                + sale[wybranaSala] + ", "
                + liczbaOsob() + ", "
                + godzina + ", "
                + (cbTort.isChecked() ? "z tortem" : "bez tortu");
        tvPodsumowanie.setText(tresc);
        new AlertDialog.Builder(this)
                .setTitle("Rezerwacja")
                .setMessage(tresc)
                .setPositiveButton("OK", null)
                .show();
    }
}
