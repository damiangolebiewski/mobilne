Blok 9. Listy: ListView i ArrayAdapter

Faza II — łączenie umiejętności W trakcie

Wyświetlasz kolekcję na liście, dopisujesz elementy z pola edycyjnego z automatycznym odświeżaniem, reagujesz na kliknięcie elementu i stosujesz własny układ elementu listy — dokładnie tak jak w pomocach z arkuszy.

1. Cel

Po wykonaniu tego bloku będziesz potrafił:

  • połączyć tablicę lub ArrayList<String> z ListView przez ArrayAdapter,
  • dopisywać elementy do listy i odświeżać ją (add + notifyDataSetChanged),
  • obsłużyć kliknięcie elementu (setOnItemClickListener, position, getItemAtPosition),
  • ustawić separator (divider, dividerHeight) i własny układ elementu (R.layout.list_item).

Powiązanie z arkuszami: Arkusz_05 (kolekcja napisów jako źródło danych listy, dopisanie + odświeżenie, separator w kolorze, 3 elementy startowe z pliku) i Arkusz_10 (lista gatunków, kliknięcie elementu, wysokość wg liczby elementów). Pomoc Android Studio w arkuszach: ArrayAdapter, setAdapter, notifyDataSetChanged, setOnItemClickListener, getItemAtPosition.

2. Krótkie przypomnienie

Trzy elementy: dane → adapter → lista

Java
ArrayList<String> notatki = new ArrayList<>();            // 1. dane (import java.util.ArrayList)
notatki.add("Zakupy: chleb, masło, ser");

ArrayAdapter<String> adapter =                           // 2. adapter
        new ArrayAdapter<>(this, android.R.layout.simple_list_item_1, notatki);

ListView lvNotatki = findViewById(R.id.lvNotatki);       // 3. lista
lvNotatki.setAdapter(adapter);

android.R.layout.simple_list_item_1 to gotowy, systemowy układ jednego wiersza (zwróć uwagę na android. na początku).

Dopisanie elementu (Arkusz_05)

Java
notatki.add(etNowy.getText().toString());   // dopisz do KOLEKCJI (na koniec)
adapter.notifyDataSetChanged();              // powiadom listę — bez tego nic się nie zmieni

Do listy, którą chcesz powiększać, użyj ArrayList. Arrays.asList(tablica) daje listę o stałym rozmiarze — add rzuci UnsupportedOperationException. Bezpiecznie: new ArrayList<>(Arrays.asList("a", "b", "c")).

Kliknięcie elementu (Arkusz_10)

Java
lvGatunki.setOnItemClickListener((parent, view, position, id) -> {
    String wybrany = (String) parent.getItemAtPosition(position);   // lub gatunki[position]
    ...
});

position to indeks klikniętego elementu (od 0) — pasuje do indeksów tablic równoległych.

Wygląd listy

WymaganieXML

Własny układ elementu (jak w pomocy z arkusza)

Plik res/layout/list_item.xml (prawy przycisk na layout → New → Layout Resource File):

XML
<TextView xmlns:android="http://schemas.android.com/apk/res/android"
    android:id="@+id/tvElement"
    android:layout_width="match_parent"

Java
adapter = new ArrayAdapter<>(this, R.layout.list_item, R.id.tvElement, lektury);

Ćwiczenie natychmiastowe: w przykładzie dodaj piąte miasto do tablicy i uruchom. Potem zmień layout_height listy na 0dp z wagą 1 — co się zmieniło?

java/com/example/egzamin/MainActivity.java
package com.example.egzamin;

import android.os.Bundle;
import android.widget.ArrayAdapter;
import android.widget.ListView;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private final String[] miasta = {"Pułtusk", "Ciechanów", "Warszawa", "Płock"};

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        TextView tvWybor = findViewById(R.id.tvWybor);
        ListView lvMiasta = findViewById(R.id.lvMiasta);

        // dane (tablica) -> adapter -> lista na ekranie
        ArrayAdapter<String> adapter = new ArrayAdapter<>(this, android.R.layout.simple_list_item_1, miasta);
        lvMiasta.setAdapter(adapter);

        // kliknięcie elementu: position = indeks w tablicy (od 0)
        lvMiasta.setOnItemClickListener((parent, view, position, id) -> {
            String miasto = (String) parent.getItemAtPosition(position);
            tvWybor.setText("Wybrano: " + miasto + " (pozycja " + (position + 1) + ")");
        });
    }
}

4. Mikroćwiczenia

Ćwiczenie 9.1 — Zapisz adapter

Masz String[] gatunki = {"Pies", "Kot", "Świnka morska"}; i ListView lvGatunki. Napisz dwie linie, które wyświetlą gatunki na liście.

Sprawdź odpowiedź
Java
ArrayAdapter<String> adapter = new ArrayAdapter<>(this, android.R.layout.simple_list_item_1, gatunki);
lvGatunki.setAdapter(adapter);

Ćwiczenie 9.2 — Dlaczego lista się nie zmienia?

Po kliknięciu DODAJ kod wykonuje notatki.add(tekst);. W Logcat nie ma błędu, ale na liście nie pojawia się nowy element. Co dopisać?

Sprawdź odpowiedź

adapter.notifyDataSetChanged(); — adapter musi być polem klasy, żeby był dostępny w obsłudze przycisku.

Ćwiczenie 9.3 — Stały rozmiar

List<String> lista = Arrays.asList("a", "b"); lista.add("c"); — co się stanie? Jak to naprawić?

Sprawdź odpowiedź

Wyjątek UnsupportedOperationException (lista stałego rozmiaru). Naprawa: ArrayList<String> lista = new ArrayList<>(Arrays.asList("a", "b"));.

Ćwiczenie 9.4 — Tablice równoległe

Lista gatunków „Pies”, „Kot”, „Świnka morska”, maksymalne wieki 18, 20, 9 (Arkusz_10). Po kliknięciu ustaw maksimum suwaka sbWiek. Napisz obsługę bez if.

Sprawdź odpowiedź
Java
private final int[] maksWiek = {18, 20, 9};
...
lvGatunki.setOnItemClickListener((parent, view, position, id) -> {
    sbWiek.setMax(maksWiek[position]);
    tvWiek.setText(String.valueOf(sbWiek.getProgress()));
});

Ćwiczenie 9.5 — Separator

Arkusz_05: „kolor separatora Crimson, separator jest widoczny (np. poprzez ustawienie wysokości separatora)”. Dopisz atrybuty ListView.

Sprawdź odpowiedź

android:divider="#DC143C" i android:dividerHeight="2dp" (sam kolor bez wysokości może dać niewidoczną linię).

5. Zadanie prowadzone

Lista zakupów

⏱ ok. 35 min

Mechanizm z Arkusza_05 w innym kontekście: pole i przycisk w jednym rzędzie, lista z separatorem, licznik pozycji. Dodatkowo — walidacja pustego pola.

Działanie: na starcie lista zawiera „chleb” i „mleko”, napis „Pozycji: 2”. DODAJ dopisuje produkt na koniec listy, czyści pole i aktualizuje licznik. Puste pole → Toast „Wpisz nazwę produktu”, lista bez zmian.

Kroki:

  1. XML: tytuł (#EF6C00), rząd [pole (0dp, waga 1) + przycisk DODAJ], napis licznika, ListView wypełniający resztę ekranu z separatorem #EF6C00 1dp.
  2. Java: pola ArrayList<String> zakupy, ArrayAdapter<String> adapter.
  3. W onCreate: dwa elementy startowe, adapter, setAdapter.
  4. DODAJ: odczyt, walidacja, add, notifyDataSetChanged, czyszczenie, licznik (zakupy.size()).

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Adapter musisz wywołać w obsłudze przycisku — zadeklaruj go jako pole klasy, nie zmienną lokalną w onCreate.

Poziom 2 — konkretna wskazówka

Kolejność w DODAJ: zmień dane → notifyDataSetChanged() → wyczyść pole → licznik. Czyszczenie: etProdukt.setText("").

Poziom 3 — pseudokod / struktura
Tekst
pola: zakupy = new ArrayList<>(), adapter, etProdukt, tvLiczba
onCreate: zakupy.add("chleb"); zakupy.add("mleko"); adapter; setAdapter
DODAJ: produkt ← pole.trim()
       jeśli pusty → Toast; koniec
       zakupy.add(produkt); adapter.notifyDataSetChanged()
       pole ← ""; licznik ← "Pozycji: " + zakupy.size()
Poziom 4 — fragment implementacji
Java
btnDodaj.setOnClickListener(v -> {
    String produkt = etProdukt.getText().toString().trim();
    if (produkt.isEmpty()) {
        Toast.makeText(this, "Wpisz nazwę produktu", Toast.LENGTH_SHORT).show();
        return;
    }
    zakupy.add(produkt);
    adapter.notifyDataSetChanged();
    etProdukt.setText("");
    tvLiczba.setText("Pozycji: " + zakupy.size());
});

java/com/example/egzamin/MainActivity.java
package com.example.egzamin;

import android.os.Bundle;
import android.widget.ArrayAdapter;
import android.widget.Button;
import android.widget.EditText;
import android.widget.ListView;
import android.widget.TextView;
import android.widget.Toast;

import java.util.ArrayList;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private final ArrayList<String> zakupy = new ArrayList<>();
    private ArrayAdapter<String> adapter;
    private EditText etProdukt;
    private TextView tvLiczba;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        etProdukt = findViewById(R.id.etProdukt);
        tvLiczba = findViewById(R.id.tvLiczba);
        ListView lvZakupy = findViewById(R.id.lvZakupy);
        Button btnDodaj = findViewById(R.id.btnDodaj);

        zakupy.add("chleb");
        zakupy.add("mleko");
        adapter = new ArrayAdapter<>(this, android.R.layout.simple_list_item_1, zakupy);
        lvZakupy.setAdapter(adapter);

        btnDodaj.setOnClickListener(v -> {
            String produkt = etProdukt.getText().toString().trim();
            if (produkt.isEmpty()) {
                Toast.makeText(this, "Wpisz nazwę produktu", Toast.LENGTH_SHORT).show();
                return;
            }
            zakupy.add(produkt);             // 1. zmiana danych
            adapter.notifyDataSetChanged();  // 2. powiadomienie listy
            etProdukt.setText("");           // 3. porządek w formularzu
            tvLiczba.setText("Pozycji: " + zakupy.size());
        });
    }
}

6. Zadanie samodzielne

Kursy wakacyjne — szczegóły po kliknięciu

⏱ ok. 35 min

Lista stała (z tablicy), a kliknięcie pokazuje dane z tablic równoległych i wynik obliczenia.

  • Kursy: „Python od zera” (20 h, 300 zł), „Tworzenie stron WWW” (30 h, 450 zł), „Aplikacje mobilne” (40 h, 600 zł), „Sieci komputerowe” (25 h, 380 zł).
  • Lista o wysokości dopasowanej do liczby elementów, separator #1D4F91 2dp.
  • Pod listą pole szczegółów (tło #E8EEFB, padding 12dp), na starcie „Kliknij kurs, aby zobaczyć szczegóły”.
  • Po kliknięciu: nazwa kursu, a w nowej linii „<h> godzin, <cena> zł (<cena/h> zł/h)” z dwoma miejscami po przecinku.

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Trzy tablice (String[], int[], int[]) o tych samych indeksach. W obsłudze kliknięcia używasz position.

Poziom 2 — konkretna wskazówka

Nowa linia w tekście: \n. Dzielenie z ułamkiem: (double) ceny[position] / godziny[position].

Poziom 3 — pseudokod / struktura
Tekst
kliknięcie(position):
    zaGodzine ← cena[position] / godziny[position] (double)
    tekst ← nazwa + "\n" + godziny + " godzin, " + cena + " zł (" + format(zaGodzine) + " zł/h)"
Poziom 4 — fragment implementacji
Java
lvKursy.setOnItemClickListener((parent, view, position, id) -> {

package com.example.egzamin;

import android.os.Bundle;
import android.widget.ArrayAdapter;
import android.widget.ListView;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private final String[] kursy = {"Python od zera", "Tworzenie stron WWW", "Aplikacje mobilne", "Sieci komputerowe"};
    private final int[] godziny = {20, 30, 40, 25};
    private final int[] ceny = {300, 450, 600, 380};

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        ListView lvKursy = findViewById(R.id.lvKursy);
        TextView tvSzczegoly = findViewById(R.id.tvSzczegoly);

        ArrayAdapter<String> adapter = new ArrayAdapter<>(this, android.R.layout.simple_list_item_1, kursy);
        lvKursy.setAdapter(adapter);

        lvKursy.setOnItemClickListener((parent, view, position, id) -> {
            double zaGodzine = (double) ceny[position] / godziny[position];
            tvSzczegoly.setText(String.format("%s\n%d godzin, %d zł (%.2f zł/h)",
                    kursy[position], godziny[position], ceny[position], zaGodzine));
        });
    }
}

7. Zadanie w stylu INF.04

Moje lektury

⏱ ok. 50 min

Wykonaj aplikację mobilną do prowadzenia listy lektur. Dane początkowe zapisano w pliku lektury.txt w archiwum zasoby_b09-inf.zip.

Krok 1–6: analiza polecenia. Zanim otworzysz Android Studio, wypisz na kartce (lub w komentarzu) odpowiedzi:
INTERFEJSCo musi znaleźć się na ekranie?
DANECo wpisuje / wybiera użytkownik?
ZDARZENIACo uruchamia działania?
LOGIKACo trzeba policzyć / sprawdzić / zmienić?
WYNIKCo aplikacja wyświetla lub zmienia?
WYGLĄDKolory, rozmiary, marginesy, rozkłady?
Porównaj swoją analizę z wzorcową
INTERFEJStytuł; rząd: pole + przycisk DODAJ; napis liczby; napis „Wybrano”; lista (własny układ elementu); autor
DANEtytuł lektury wpisany w polu; kliknięty element listy
ZDARZENIAkliknięcie DODAJ; kliknięcie elementu listy
LOGIKAArrayList + adapter z R.layout.list_item; walidacja: puste pole, duplikat (contains); dopisanie + notifyDataSetChanged
WYNIKnowy element na końcu listy, „Liczba lektur: n”, „Wybrano: <tytuł> (pozycja n)”, Toast przy błędzie
WYGLĄDtło #EFEBE9; tytuł #4E342E biały; przycisk #8D6E63; separator #8D6E63 2dp; element listy 18sp, padding 10, kolor #3E2723

Elementy aplikacji:

  • Napis „Moje lektury”.
  • Pole edycyjne z podpowiedzią „Tytuł lektury” i przycisk „DODAJ” w jednym rzędzie.
  • Napis „Liczba lektur: 3”.
  • Napis „Wybrano: —”.
  • Lista (element widoku listy).
  • Napis „Autor: ”, dalej numer zdającego (na dole ekranu).

Działanie aplikacji:

  • W stanie początkowym lista zawiera 3 lektury z pliku lektury.txt (można je wpisać do kodu).
  • Po wybraniu „DODAJ” tytuł z pola jest dopisywany jako ostatni element listy, lista odświeża się automatycznie, pole jest czyszczone, a napis liczby lektur jest aktualizowany.
  • Jeżeli pole jest puste — komunikat w oknie Toast „Wpisz tytuł lektury”. Jeżeli taki tytuł już jest na liście — Toast „Ta lektura już jest na liście”. W obu przypadkach lista się nie zmienia.
  • Kliknięcie elementu listy wyświetla „Wybrano: <tytuł> (pozycja <n>)”, gdzie n liczone jest od 1.

Założenia aplikacji:

  • Interfejs w XML; rozkład liniowy pionowy z zagnieżdżonym rozkładem poziomym dla pola i przycisku; pole zajmuje całą wolną szerokość rzędu.
  • Lektury zapisane w kolekcji ArrayList<String> połączonej z listą jako jej źródło danych.
  • Element listy zdefiniowany we własnym pliku układu list_item.xml: czcionka 18, marginesy wewnętrzne 10, kolor #3E2723.
  • Tło strony #EFEBE9; tytuł: tło #4E342E, biała czcionka, największa, marginesy wewnętrzne 10. Przycisk: tło #8D6E63, biała czcionka.
  • Separator listy koloru #8D6E63, wysokość 2. Lista wypełnia wolną przestrzeń między napisami a podpisem autora.

Zasoby do zadania

Pobierz wszystkie: zasoby_b09-inf.zip. Obrazy skopiuj do app/src/main/res/drawable (nazwy: małe litery, bez spacji i myślników).

Checklista zadania

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Zacznij od list_item.xml i adaptera z czterema argumentami — bez tego lista nie wyświetli się w wymaganym stylu.

Poziom 2 — konkretna wskazówka

Duplikat: lektury.contains(tytul). Lista startowa: new ArrayList<>(Arrays.asList("Pan Tadeusz", "Lalka", "Zbrodnia i kara")).

Poziom 3 — pseudokod / struktura
Tekst
DODAJ → dodajLekture():
    tytul ← pole.trim()
    jeśli pusty → Toast "Wpisz tytuł lektury"

package com.example.egzamin;

import android.os.Bundle;
import android.widget.ArrayAdapter;
import android.widget.Button;
import android.widget.EditText;
import android.widget.ListView;
import android.widget.TextView;
import android.widget.Toast;

import java.util.ArrayList;
import java.util.Arrays;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    // dane początkowe skopiowane z pliku lektury.txt
    private final ArrayList<String> lektury = new ArrayList<>(Arrays.asList("Pan Tadeusz", "Lalka", "Zbrodnia i kara"));
    private ArrayAdapter<String> adapter;

    private EditText etTytul;
    private TextView tvLiczba, tvWybrano;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        etTytul = findViewById(R.id.etTytul);
        tvLiczba = findViewById(R.id.tvLiczba);
        tvWybrano = findViewById(R.id.tvWybrano);
        ListView lvLektury = findViewById(R.id.lvLektury);
        Button btnDodaj = findViewById(R.id.btnDodaj);

        // własny układ elementu listy: R.layout.list_item, w nim TextView o id tvElement
        adapter = new ArrayAdapter<>(this, R.layout.list_item, R.id.tvElement, lektury);
        lvLektury.setAdapter(adapter);

        btnDodaj.setOnClickListener(v -> dodajLekture());

        lvLektury.setOnItemClickListener((parent, view, position, id) ->
                tvWybrano.setText("Wybrano: " + lektury.get(position) + " (pozycja " + (position + 1) + ")"));
    }

    private void dodajLekture() {
        String tytul = etTytul.getText().toString().trim();
        if (tytul.isEmpty()) {
            Toast.makeText(this, "Wpisz tytuł lektury", Toast.LENGTH_SHORT).show();
        } else if (lektury.contains(tytul)) {
            Toast.makeText(this, "Ta lektura już jest na liście", Toast.LENGTH_SHORT).show();
        } else {
            lektury.add(tytul);
            adapter.notifyDataSetChanged();
            etTytul.setText("");
            tvLiczba.setText("Liczba lektur: " + lektury.size());
        }
    }
}
