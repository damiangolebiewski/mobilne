Blok 3. Formularz: odczyt danych, konwersja i obliczenia

Faza I — wyrównanie W trakcie

Pobierasz tekst z pól edycyjnych, zamieniasz go na liczby, liczysz i pokazujesz wynik. Uczysz się rozpoznać awarię w Logcat i zabezpieczyć konwersję.

1. Cel

Po wykonaniu tego bloku będziesz potrafił:

  • dodać pole EditText z podpowiedzią (hint) i właściwym typem klawiatury (inputType),
  • odczytać tekst z pola: getText().toString().trim(),
  • zamienić tekst na liczbę (Integer.parseInt, Double.parseDouble) i zabezpieczyć się przed błędem (try/catch),
  • sformatować wynik (String.format("%.2f", …)) i pokazać go w TextView lub Toast,
  • odczytać przyczynę awarii w oknie Logcat.

Java
String tekst = etKwota.getText().toString().trim();   // Editable → String, bez spacji
double kwota = Double.parseDouble(tekst);              // "12.5" → 12.5
int sztuki  = Integer.parseInt("3");                   // "3" → 3
tvWynik.setText(String.format("%.2f zł", kwota * 1.23)); // 2 miejsca po przecinku

Integer.parseInt("") (puste pole) i Integer.parseInt("abc") rzucają NumberFormatException — aplikacja się zamyka. Zabezpiecz konwersję:

Java
try {
    int liczba = Integer.parseInt(etLiczba.getText().toString().trim());
    tvWynik.setText("Kwadrat: " + (liczba * liczba));
} catch (NumberFormatException e) {
    Toast.makeText(this, "Wpisz liczbę", Toast.LENGTH_SHORT).show();
}

Gdy aplikacja się zamyka — Logcat

Na dole Android Studio otwórz Logcat, w filtrze wpisz level:error i szukaj linii FATAL EXCEPTION. Kilka linii niżej jest nazwa wyjątku i numer linii w MainActivity.java (niebieski link). Przykład:

Tekst
FATAL EXCEPTION: main
java.lang.NumberFormatException: For input string: ""
    at java.lang.Integer.parseInt(Integer.java:627)
    at com.example.egzamin.MainActivity.lambda$onCreate$0(MainActivity.java:31)

Liczba z przecinkiem: w polskich ustawieniach klawiatura może wstawić „,”. Double.parseDouble("2,5") się nie uda — użyj tekst.replace(',', '.').

Ćwiczenie natychmiastowe: w przykładzie poniżej zostaw pole roku puste i kliknij POWITAJ. Potem usuń try/catch, powtórz i znajdź wyjątek w Logcat. Przywróć try/catch.

package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.EditText;
import android.widget.TextView;
import android.widget.Toast;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private static final int BIEZACY_ROK = 2026;

    private EditText etImie;
    private EditText etRok;
    private TextView tvWynik;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        etImie = findViewById(R.id.etImie);
        etRok = findViewById(R.id.etRok);
        tvWynik = findViewById(R.id.tvWynik);
        Button btnPowitaj = findViewById(R.id.btnPowitaj);

        btnPowitaj.setOnClickListener(v -> {
            // 1. odczyt: getText() zwraca Editable -> zamieniamy na String
            String imie = etImie.getText().toString().trim();
            String rokTekst = etRok.getText().toString().trim();

            // 2. konwersja tekst -> liczba (może się nie udać!)
            try {
                int rok = Integer.parseInt(rokTekst);
                int wiek = BIEZACY_ROK - rok;
                // 3. wynik
                tvWynik.setText("Cześć, " + imie + "! W tym roku kończysz " + wiek + " lat.");
            } catch (NumberFormatException e) {
                Toast.makeText(this, "Podaj rok urodzenia", Toast.LENGTH_SHORT).show();
            }
        });
    }
}

4. Mikroćwiczenia

Ćwiczenie 3.1 — Pole na hasło

Napisz EditText z podpowiedzią „Podaj hasło”, który ukrywa wpisywane znaki i zajmuje całą szerokość (jak w Arkuszu_01).

Sprawdź odpowiedź
XML
<EditText
    android:id="@+id/etHaslo"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:hint="Podaj hasło"
    android:inputType="textPassword" />

Ćwiczenie 3.2 — Znajdź błąd kompilacji

String imie = etImie.getText(); — dlaczego się nie kompiluje?

Sprawdź odpowiedź

getText() zwraca Editable, a nie String. Poprawnie: etImie.getText().toString().

Ćwiczenie 3.3 — Dzielenie całkowite

Oceny 4, 5, 5. Kod: double srednia = (o1 + o2 + o3) / 3; Jaki będzie wynik i dlaczego? Popraw.

Sprawdź odpowiedź

Wynik 4.0 zamiast 4.67 — int / int daje int (część ułamkowa jest obcinana przed zapisem do double). Poprawnie: / 3.0.

Ćwiczenie 3.4 — Formatowanie

Zmienna double cena = 12.5;. Wyświetl w tvCena tekst „Cena: 12,50 zł” (dwa miejsca po przecinku).

Sprawdź odpowiedź

tvCena.setText(String.format("Cena: %.2f zł", cena)); — w polskich ustawieniach systemu separatorem będzie przecinek.

Ćwiczenie 3.5 — Czytanie Logcat

Tekst
java.lang.NumberFormatException: For input string: "12a"
    at com.example.egzamin.MainActivity.oblicz(MainActivity.java:44)

Co wpisał użytkownik, w której metodzie i linii wystąpił błąd, jak go uniknąć?

Sprawdź odpowiedź

Użytkownik wpisał „12a”; błąd w metodzie oblicz, linia 44 MainActivity.java. Zabezpieczenie: inputType="number" w XML (klawiatura tylko z cyframi) oraz try/catch (NumberFormatException e) w kodzie.

Ćwiczenie 3.6 — Toast

Napisz linię, która wyświetla krótki dymek „Zapisano”. Jaka jest różnica między LENGTH_SHORT i LENGTH_LONG? Co się stanie, gdy zapomnisz .show()?

Sprawdź odpowiedź

Toast.makeText(this, "Zapisano", Toast.LENGTH_SHORT).show(); — SHORT ok. 2 s, LONG ok. 3,5 s. Bez .show() nic się nie wyświetli (i nie ma błędu — łatwo przeoczyć).

5. Zadanie prowadzone

Kantor: przelicznik walut

⏱ ok. 40 min

Przelicznik kwoty w złotych na euro lub dolary. Dwa przyciski wywołują tę samą metodę z innym kursem.

Działanie: kurs EUR = 4,30, kurs USD = 3,95 (stałe w kodzie). Wynik = kwota / kurs, oba z dwoma miejscami po przecinku: „100,00 PLN = 23,26 EUR”. Gdy pole jest puste lub niepoprawne — Toast „Wpisz poprawną kwotę”.

Kroki:

  1. XML: tytuł, EditText (numberDecimal, podpowiedź „Kwota w PLN”), rząd dwóch przycisków (wagi), napis wyniku.
  2. Java: stałe KURS_EUR, KURS_USD; pola etKwota, tvWynik.
  3. Metoda przelicz(double kurs, String waluta) z try/catch.
  4. Przyciski: btnEur.setOnClickListener(v -> przelicz(KURS_EUR, "EUR")); i analogicznie USD.
  5. Test: 100 → 23,26 EUR i 25,32 USD; puste pole → Toast; „12,5” (z przecinkiem) też działa.

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Cała logika jest w jednej metodzie z dwoma parametrami. Obsługi przycisków tylko ją wywołują.

Poziom 2 — konkretna wskazówka

Przecinek zamień na kropkę przed konwersją: …toString().trim().replace(',', '.'). Formatowanie kilku liczb naraz: String.format("%.2f PLN = %.2f %s", kwota, wynik, waluta).

Poziom 3 — pseudokod / struktura
Tekst
przelicz(kurs, waluta):
    tekst ← pole kwoty (trim, przecinek → kropka)
    spróbuj:
        kwota ← parseDouble(tekst)
        wynik ← kwota / kurs
        tvWynik ← sformatowany tekst
    błąd konwersji:
        Toast "Wpisz poprawną kwotę"
Poziom 4 — fragment implementacji
Java
private void przelicz(double kurs, String waluta) {
    String tekst = etKwota.getText().toString().trim().replace(',', '.');
    try {
        double kwota = Double.parseDouble(tekst);
        tvWynik.setText(String.format("%.2f PLN = %.2f %s", kwota, kwota / kurs, waluta));
    } catch (NumberFormatException e) {
        Toast.makeText(this, "Wpisz poprawną kwotę", Toast.LENGTH_SHORT).show();
    }
}

package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.EditText;
import android.widget.TextView;
import android.widget.Toast;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private static final double KURS_EUR = 4.30;
    private static final double KURS_USD = 3.95;

    private EditText etKwota;
    private TextView tvWynik;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        etKwota = findViewById(R.id.etKwota);
        tvWynik = findViewById(R.id.tvWynik);
        Button btnEur = findViewById(R.id.btnEur);
        Button btnUsd = findViewById(R.id.btnUsd);

        btnEur.setOnClickListener(v -> przelicz(KURS_EUR, "EUR"));
        btnUsd.setOnClickListener(v -> przelicz(KURS_USD, "USD"));
    }

    private void przelicz(double kurs, String waluta) {
        String tekst = etKwota.getText().toString().trim().replace(',', '.');
        try {
            double kwota = Double.parseDouble(tekst);
            double wynik = kwota / kurs;
            tvWynik.setText(String.format("%.2f PLN = %.2f %s", kwota, wynik, waluta));
        } catch (NumberFormatException e) {
            Toast.makeText(this, "Wpisz poprawną kwotę", Toast.LENGTH_SHORT).show();
        }
    }
}

7. Zadanie w stylu INF.04

Kalkulator spalania paliwa

⏱ ok. 45 min

Wykonaj aplikację mobilną obliczającą średnie spalanie samochodu i koszt przejechania 100 km.

Krok 1–6: analiza polecenia. Zanim otworzysz Android Studio, wypisz na kartce (lub w komentarzu) odpowiedzi:
INTERFEJSCo musi znaleźć się na ekranie?
DANECo wpisuje / wybiera użytkownik?
ZDARZENIACo uruchamia działania?
LOGIKACo trzeba policzyć / sprawdzić / zmienić?
WYNIKCo aplikacja wyświetla lub zmienia?
WYGLĄDKolory, rozmiary, marginesy, rozkłady?
Porównaj swoją analizę z wzorcową
INTERFEJStytuł, 3 pola edycyjne, przycisk, 2 napisy wyników, napis autora
DANEdystans (km), litry, cena za litr — liczby dziesiętne
ZDARZENIAkliknięcie „OBLICZ”
LOGIKAspalanie = litry / km × 100; koszt = spalanie × cena; walidacja: pola niepuste, dystans > 0
WYNIKdwa napisy z wynikiem (2 miejsca po przecinku) lub komunikat błędu
WYGLĄDtło #ECEFF1; tytuł #37474F biały; pola na całą szerokość; przycisk #FF8F00 czarny pogrubiony; wyniki wyśrodkowane

Elementy aplikacji:

  • Napis „Spalanie paliwa”.
  • Trzy pola edycyjne z podpowiedziami: „Przejechane km”, „Zatankowane litry”, „Cena za litr (zł)”; pola przyjmują liczby dziesiętne.
  • Przycisk „OBLICZ”.
  • Napisy „Spalanie: – l/100 km” i „Koszt 100 km: – zł”.
  • Napis „Autor: ”, dalej numer zdającego.

Działanie aplikacji:

  • Po wybraniu „OBLICZ”: spalanie = litry / km · 100, koszt 100 km = spalanie · cena za litr.
  • Wyniki są wyświetlane z dokładnością do dwóch miejsc po przecinku: „Spalanie: 6,64 l/100 km”, „Koszt 100 km: 43,10 zł”.
  • Jeżeli którekolwiek pole jest puste, zawiera niepoprawną liczbę lub dystans nie jest większy od 0 — w pierwszym napisie pojawia się „Uzupełnij poprawnie wszystkie pola”, drugi napis jest pusty. Aplikacja nie może się zamknąć.
  • Wpisanie liczby z przecinkiem (np. „42,5”) daje ten sam wynik co z kropką.

Założenia aplikacji:

  • Interfejs w XML, rozkład liniowy pionowy.

java/com/example/egzamin/MainActivity.java
package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.EditText;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private EditText etDystans, etPaliwo, etCena;
    private TextView tvSpalanie, tvKoszt;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        etDystans = findViewById(R.id.etDystans);
        etPaliwo = findViewById(R.id.etPaliwo);
        etCena = findViewById(R.id.etCena);
        tvSpalanie = findViewById(R.id.tvSpalanie);
        tvKoszt = findViewById(R.id.tvKoszt);
        Button btnOblicz = findViewById(R.id.btnOblicz);

        btnOblicz.setOnClickListener(v -> oblicz());
    }

    private double odczytajLiczbe(EditText pole) {
        String tekst = pole.getText().toString().trim().replace(',', '.');
        return Double.parseDouble(tekst);   // rzuca NumberFormatException, gdy pole jest puste
    }

    private void oblicz() {
        try {
            double dystans = odczytajLiczbe(etDystans);
            double paliwo = odczytajLiczbe(etPaliwo);
            double cena = odczytajLiczbe(etCena);
            if (dystans <= 0) {
                pokazBlad();
                return;
            }
            double spalanie = paliwo / dystans * 100;
            double koszt = spalanie * cena;
            tvSpalanie.setText(String.format("Spalanie: %.2f l/100 km", spalanie));
            tvKoszt.setText(String.format("Koszt 100 km: %.2f zł", koszt));
        } catch (NumberFormatException e) {
            pokazBlad();
        }
    }

    private void pokazBlad() {
        tvSpalanie.setText("Uzupełnij poprawnie wszystkie pola");
        tvKoszt.setText("");
    }
}

Zbuduj w 15 minut: wzrost w cm (number), masa w kg (numberDecimal), przycisk, wynik „BMI: 22,49”. BMI = masa / (wzrost_m²).
