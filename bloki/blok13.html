Blok 13. Tryb egzaminacyjny I: pełne zadania na czas

Faza III — tryb egzaminacyjny W trakcie

Dwa nowe, pełne zadania egzaminacyjne rozwiązywane według workflow 10 kroków: formularz z walidacją i obliczeniami oraz quiz z obrazami, polami radio i cyklem pytań.

1. Cel

Po wykonaniu tego bloku będziesz potrafił:

  • zastosować workflow 10 kroków do zadania, którego wcześniej nie widziałeś,
  • zaplanować drzewo widoków i zdarzenia przed pisaniem kodu,
  • zbudować w limicie czasu aplikację łączącą walidację, suwak, pola radio i obliczenia,
  • zbudować quiz: obraz i odpowiedzi z tablic, sprawdzanie, punkty, koniec gry i restart.
Plan czasu (4 × 45 min = 180 min)
Przypomnienie (workflow)10 min
Przykład (analiza)10 min
Mikroćwiczenia (sprint)20 min
Rozgrzewka20 min
Próbny egzamin — zadanie 150 min
Próbny egzamin — zadanie 260 min
Samoocena + mini-test10 min
Razem180 min

Powiązanie z arkuszami: zadanie 1 łączy wzorce W2 (walidacja tekstu jak Arkusze 01/06), W4 (suwak z przesunięciem jak 07/10) i radio + pole wyboru (desktop 04/06); zadanie 2 łączy W6 (obraz z tablicy jak 12), W1 z indeksem cyklicznym (07) i liczenie punktów (12). Żadne nie kopiuje arkusza.

Zasada: najpierw działający szkielet, potem szczegóły. Aplikacja, która się uruchamia i realizuje 80% wymagań, daje więcej punktów niż „prawie gotowa”, która się nie kompiluje. Po każdej większej zmianie — uruchom.

3. Przykład: analiza specyfikacji krok po kroku

Specyfikacja (fragment): „Aplikacja «Pomiar tętna». Pole edycyjne z podpowiedzią «Wiek» (tylko cyfry). Suwak «Tętno» 40–200, wartość obok suwaka. Przycisk «OCEŃ». Po wybraniu przycisku wyświetlany jest napis «Tętno <x>: w normie», jeśli x mieści się w przedziale 60–100, «za niskie» poniżej 60, «za wysokie» powyżej. Dla wieku powyżej 65 górna granica normy wynosi 90. Gdy wiek nie jest podany — «Podaj wiek». Tło tytułu #C62828.”

Krok 2–6 (analiza):

INTERFEJStytuł, EditText wiek, rząd [„Tętno:” + SeekBar + wartość], przycisk OCEŃ, napis wyniku
DANEwiek (int), tętno z suwaka (40..200 → max=160, wartość = progress + 40)
ZDARZENIAzmiana suwaka (napis obok), kliknięcie OCEŃ
LOGIKAwalidacja wieku; górna granica = wiek > 65 ? 90 : 100; trzy przypadki
WYNIKnapis „Tętno x: w normie / za niskie / za wysokie” lub „Podaj wiek”
WYGLĄDtło tytułu #C62828 (reszta wg obrazu)

Kolejność pracy (krok 7–8):

  1. XML: pion → tytuł, pole, rząd (napis, suwak 0dp+waga, napis), przycisk, wynik. Uruchom.
  2. Java: pola kontrolek → listener suwaka (napis progress + 40) → uruchom → obsługa OCEŃ z walidacją → uruchom → trzy przypadki → testy granic: 59, 60, 100, 101 oraz wiek 70 i tętno 95.

Zauważ: każdy element tej analizy już znasz (blok 3, 4, 8). Egzamin łączy znane wzorce w nowej kombinacji.

Ćwiczenie 13.5 — Sprint 5 (2 min): indeks zaznaczonego radio

Masz RadioButton[] opcje (3 pola w grupie rg). Napisz metodę zwracającą indeks zaznaczonego pola lub −1.

Sprawdź odpowiedź
Java
private int zaznaczony() {
    int id = rg.getCheckedRadioButtonId();
    for (int i = 0; i < opcje.length; i++) {
        if (opcje[i].getId() == id) return i;
    }
    return -1;
}

5. Zadanie prowadzone (rozgrzewka)

Rozgrzewka: konwerter temperatur (20 min)

⏱ ok. 20 min

Krótka aplikacja na rozgrzewkę — ćwiczy tylko kroki 1–8 w szybkim tempie. Najpierw zapisz analizę (6 wierszy), potem koduj.

  • Pole temperatury w °C (liczby dziesiętne, także ujemne). Pola radio „na °F” (domyślne) i „na K”.
  • PRZELICZ: °F = C · 9/5 + 32 (1 miejsce po przecinku), K = C + 273,15 (2 miejsca). Format: „25,0 °C = 77,0 °F”, „25,0 °C = 298,15 K”.
  • Puste lub błędne pole → „Podaj temperaturę”.

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Liczby ujemne w polu: android:inputType="numberDecimal|numberSigned".

Poziom 2 — konkretna wskazówka

Rozgałęzienie po rgSkala.getCheckedRadioButtonId() == R.id.rbKelwin.

Poziom 3 — pseudokod / struktura
Tekst
PRZELICZ: spróbuj c ← parseDouble; jeśli K → "%.1f °C = %.2f K"; inaczej → "%.1f °C = %.1f °F"; błąd → "Podaj temperaturę"
Poziom 4 — fragment implementacji

String.format("%.1f °C = %.1f °F", c, c * 9 / 5 + 32)

package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.EditText;
import android.widget.RadioGroup;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private EditText etCelsjusz;
    private RadioGroup rgSkala;
    private TextView tvWynik;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        etCelsjusz = findViewById(R.id.etCelsjusz);
        rgSkala = findViewById(R.id.rgSkala);
        tvWynik = findViewById(R.id.tvWynik);
        Button btnPrzelicz = findViewById(R.id.btnPrzelicz);

        btnPrzelicz.setOnClickListener(v -> przelicz());
    }

    private void przelicz() {
        try {
            double c = Double.parseDouble(etCelsjusz.getText().toString().trim().replace(',', '.'));
            if (rgSkala.getCheckedRadioButtonId() == R.id.rbKelwin) {
                tvWynik.setText(String.format("%.1f °C = %.2f K", c, c + 273.15));
            } else {
                tvWynik.setText(String.format("%.1f °C = %.1f °F", c, c * 9 / 5 + 32));
            }
        } catch (NumberFormatException e) {
            tvWynik.setText("Podaj temperaturę");
        }
    }
}

6. Próbny egzamin — zadanie 1

Próbny egzamin 1: Parking miejski (50 min)

⏱ ok. 50 min

Warunki próbnego egzaminu: pracuj bez zaglądania do wcześniejszych bloków i własnych projektów (wolno: ta treść, zasoby, dokumentacja Android Studio). Zmierz czas. Podpowiedzi otwieraj dopiero po upływie czasu albo gdy zupełnie utkniesz — i zapisz, z których skorzystałeś. Na koniec: zrzuty mobile1.png…, mobilna.zip, kopie plików źródłowych, srodowisko.txt.

Za pomocą środowiska programistycznego wykonaj aplikację mobilną obliczającą opłatę parkingową i uruchom ją w emulatorze. Do wykonania zadania wykorzystaj obraz z archiwum zasoby_b13-egzA.zip.

Krok 1–6: analiza polecenia. Zanim otworzysz Android Studio, wypisz na kartce (lub w komentarzu) odpowiedzi:
INTERFEJSCo musi znaleźć się na ekranie?
DANECo wpisuje / wybiera użytkownik?
ZDARZENIACo uruchamia działania?
LOGIKACo trzeba policzyć / sprawdzić / zmienić?
WYNIKCo aplikacja wyświetla lub zmienia?
WYGLĄDKolory, rozmiary, marginesy, rozkłady?
Porównaj swoją analizę z wzorcową
INTERFEJStytuł, obraz, pole rejestracji, rząd czasu (napis, suwak, wartość), 2 pola radio, pole wyboru, przycisk, napis wyniku
DANEnumer rejestracyjny (tekst), godziny 1..12, strefa, karta mieszkańca
ZDARZENIAzmiana suwaka, OBLICZ OPŁATĘ
LOGIKAwalidacja: 4–8 znaków, tylko litery/cyfry; wielkie litery; opłata = h·stawka; karta −50%; maksymalnie 40 zł
WYNIK„<NUMER>, strefa X, n h, do zapłaty: x,xx zł” lub komunikat błędu; start „Autor: …”
WYGLĄDtło #E3F2FD; tytuł #1565C0 biały; obraz 100dp wyśrodkowany; przycisk na szerokość #1565C0; wynik wyśrodkowany

Elementy aplikacji:

  • Napis „Parking miejski”.
  • Obraz parking (znak parkingu).
  • Pole edycyjne z podpowiedzią „Numer rejestracyjny”; wpisywane litery są wielkie, maksymalnie 8 znaków.
  • Rząd: napis „Czas postoju:”, suwak, napis z liczbą godzin (początkowo „1 h”). Suwak pozwala wybrać od 1 do 12 godzin.
  • Dwa pola radio w grupie: „Strefa A (5 zł/h)” (domyślnie zaznaczone), „Strefa B (3 zł/h)”.
  • Pole wyboru „Karta mieszkańca (−50%)”.
  • Przycisk „OBLICZ OPŁATĘ”.
  • Napis na wynik; w stanie początkowym „Autor: ”, dalej numer zdającego.

Działanie aplikacji:

  • Przesuwanie suwaka aktualizuje napis „<n> h”.
  • Po wybraniu „OBLICZ OPŁATĘ” sprawdzany jest numer rejestracyjny: musi mieć od 4 do 8 znaków i składać się wyłącznie z liter i cyfr. W przeciwnym razie wyświetlany jest napis „Nieprawidłowy numer rejestracyjny”.
  • Opłata = liczba godzin · stawka strefy. Karta mieszkańca obniża opłatę o 50%. Opłata nie może przekroczyć 40 zł (limit dzienny).
  • Wynik: „<NUMER>, strefa <A/B>, <n> h, do zapłaty: <kwota> zł”, numer wielkimi literami, kwota z dwoma miejscami po przecinku.

Założenia aplikacji:

  • Interfejs w XML; rozkład liniowy pionowy z zagnieżdżonym rozkładem poziomym dla czasu postoju.
  • Tło strony #E3F2FD. Tytuł: tło #1565C0, biała czcionka, największa, marginesy wewnętrzne 10.
  • Obraz: wysokość 100, wyśrodkowany. Przycisk: na całą szerokość (marginesy 10), tło #1565C0, biała czcionka. Wynik wyśrodkowany.
  • Walidacja numeru i obliczenie opłaty w osobnych metodach (metoda licząca przyjmuje liczbę godzin, strefę i informację o karcie i zwraca kwotę).

Zasoby do zadania

Pobierz wszystkie: zasoby_b13-egzA.zip. Obrazy skopiuj do app/src/main/res/drawable (nazwy: małe litery, bez spacji i myślników).

Checklista zadania

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Rozpisz wzór opłaty na przykładach z checklisty. Limit 40 zł stosujesz na końcu (po zniżce).

Poziom 2 — konkretna wskazówka

Java
private double policzOplate(int godziny, boolean strefaA, boolean karta) {
    double oplata = godziny * (strefaA ? STAWKA_A : STAWKA_B);
    if (karta) {
        oplata = oplata / 2;
    }
    return Math.min(oplata, LIMIT_DZIENNY);
}

            }
        });

        btnOblicz.setOnClickListener(v -> oblicz());
    }

    private boolean czyPoprawnaRejestracja(String numer) {
        if (numer.length() < 4 || numer.length() > 8) {
            return false;
        }
        for (int i = 0; i < numer.length(); i++) {
            if (!Character.isLetterOrDigit(numer.charAt(i))) {
                return false;
            }
        }
        return true;
    }

    private double policzOplate(int godziny, boolean strefaA, boolean karta) {
        double oplata = godziny * (strefaA ? STAWKA_A : STAWKA_B);
        if (karta) {
            oplata = oplata / 2;
        }
        return Math.min(oplata, LIMIT_DZIENNY);
    }

    private void oblicz() {
        String numer = etRejestracja.getText().toString().trim().toUpperCase();
        if (!czyPoprawnaRejestracja(numer)) {
            tvWynik.setText("Nieprawidłowy numer rejestracyjny");
            return;
        }
        int godziny = sbCzas.getProgress() + 1;
        boolean strefaA = rgStrefa.getCheckedRadioButtonId() == R.id.rbStrefaA;
        double oplata = policzOplate(godziny, strefaA, cbKarta.isChecked());
        tvWynik.setText(String.format("%s, strefa %s, %d h, do zapłaty: %.2f zł",
                numer, strefaA ? "A" : "B", godziny, oplata));
    }
}

package com.example.egzamin;

import android.os.Bundle;
import android.view.View;
import android.widget.Button;
import android.widget.ImageView;
import android.widget.RadioButton;
import android.widget.RadioGroup;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private final int[] flagi = {R.drawable.flaga_polska, R.drawable.flaga_niemcy, R.drawable.flaga_francja,
            R.drawable.flaga_wlochy, R.drawable.flaga_czechy, R.drawable.flaga_ukraina};
    private final String[][] odpowiedzi = {
            {"Kraków", "Warszawa", "Gdańsk"},
            {"Berlin", "Monachium", "Hamburg"},
            {"Lyon", "Marsylia", "Paryż"},
            {"Rzym", "Mediolan", "Neapol"},
            {"Brno", "Praga", "Ostrawa"},
            {"Lwów", "Odessa", "Kijów"}
    };
    private final int[] poprawne = {1, 0, 2, 0, 1, 2};

    private int pytanie = 0;
    private int punkty = 0;
    private boolean koniec = false;

    private ImageView ivFlaga;
    private TextView tvNumer, tvPunkty, tvInfo, tvPytanie;
    private RadioGroup rgOdpowiedzi;
    private RadioButton[] przyciski;
    private Button btnZatwierdz;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        ivFlaga = findViewById(R.id.ivFlaga);
        tvNumer = findViewById(R.id.tvNumer);
        tvPunkty = findViewById(R.id.tvPunkty);
        tvInfo = findViewById(R.id.tvInfo);
        tvPytanie = findViewById(R.id.tvPytanie);
        rgOdpowiedzi = findViewById(R.id.rgOdpowiedzi);
        przyciski = new RadioButton[]{findViewById(R.id.rbOdp1), findViewById(R.id.rbOdp2), findViewById(R.id.rbOdp3)};
        btnZatwierdz = findViewById(R.id.btnZatwierdz);

        btnZatwierdz.setOnClickListener(v -> {
            if (koniec) {
                nowaGra();
            } else {
                sprawdzOdpowiedz();
            }
        });
        pokazPytanie();
    }

    private void pokazPytanie() {
        tvNumer.setText("Pytanie " + (pytanie + 1) + "/" + flagi.length);
        ivFlaga.setImageResource(flagi[pytanie]);
        for (int i = 0; i < przyciski.length; i++) {
            przyciski[i].setText(odpowiedzi[pytanie][i]);
        }
        rgOdpowiedzi.clearCheck();
    }

    private int zaznaczonaOdpowiedz() {
        int id = rgOdpowiedzi.getCheckedRadioButtonId();
        for (int i = 0; i < przyciski.length; i++) {
            if (przyciski[i].getId() == id) {
                return i;
            }
        }
        return -1;
    }

    private void sprawdzOdpowiedz() {
        int wybrana = zaznaczonaOdpowiedz();
        if (wybrana == -1) {
            tvInfo.setText("Zaznacz odpowiedź");
            return;
        }
        int dobra = poprawne[pytanie];
        if (wybrana == dobra) {
            punkty++;
            tvInfo.setText("Dobrze!");
        } else {
            tvInfo.setText("Źle, poprawna odpowiedź: " + odpowiedzi[pytanie][dobra]);
        }
        tvPunkty.setText("Punkty: " + punkty);
        pytanie++;
        if (pytanie < flagi.length) {
            pokazPytanie();
        } else {
            koniec = true;
            tvNumer.setText("Koniec! Wynik: " + punkty + "/" + flagi.length);
            tvPytanie.setVisibility(View.GONE);
            rgOdpowiedzi.setVisibility(View.GONE);
            btnZatwierdz.setText("ZAGRAJ PONOWNIE");
        }
    }

    private void nowaGra() {
        pytanie = 0;
        punkty = 0;
        koniec = false;
        tvPunkty.setText("Punkty: 0");
        tvInfo.setText("");
        tvPytanie.setVisibility(View.VISIBLE);
        rgOdpowiedzi.setVisibility(View.VISIBLE);
        btnZatwierdz.setText("ZATWIERDŹ");
        pokazPytanie();
    }
}
