Bloki › Blok 8

Blok 8. Suwak SeekBar: wartości na żywo

Faza II — łączenie umiejętności W trakcie

Obsługujesz suwak: odczyt wartości w trakcie przesuwania, maksimum i przesunięcie zakresu, zmiana rozmiaru czcionki, obrazu i koloru. Jeden obiekt nasłuchujący dla kilku suwaków.

1. Cel

Po wykonaniu tego bloku będziesz potrafił:

  • dodać SeekBar z maksimum i wartością początkową oraz ułożyć go w rzędzie z napisami,
  • obsłużyć OnSeekBarChangeListener i reagować w onProgressChanged,
  • przesunąć zakres suwaka (np. 1..10 zamiast 0..9) i zmieniać maksimum z kodu (setMax),
  • zmieniać na żywo tekst, rozmiar czcionki (setTextSize), obraz i kolor (Color.rgb),
  • podpiąć jeden obiekt nasłuchujący do kilku suwaków.

2. Krótkie przypomnienie

SeekBar w XML

XML
<SeekBar
    android:id="@+id/sbRozmiar"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:max="40"
    android:progress="0" />

Wartości suwaka są zawsze całkowite od 0 do max (Arkusze 07 i 10: „wartość zawsze liczbą całkowitą”).

Obsługa — szkielet z pomocy arkusza

Java
sbRozmiar.setOnSeekBarChangeListener(new SeekBar.OnSeekBarChangeListener() {
    @Override
    public void onProgressChanged(SeekBar seekBar, int progress, boolean fromUser) {
        tvRozmiar.setText("Rozmiar: " + progress);   // tu logika
        tvCytat.setTextSize(progress);
    }
    @Override
    public void onStartTrackingTouch(SeekBar seekBar) { }
    @Override
    public void onStopTrackingTouch(SeekBar seekBar) { }
});

Wszystkie trzy metody muszą istnieć (to interfejs), nawet jeśli dwie są puste. Nie da się tu użyć lambdy.

Wewnątrz klasy anonimowej this oznacza obiekt nasłuchujący, nie aktywność. Toast.makeText(this, …) się nie skompiluje — użyj MainActivity.this.

Zakres od 1, a nie od 0

android:min działa dopiero od Androida 8 (API 26). Uniwersalnie: przesuń wartość w kodzie.

Java
// zakres 1..10 → max = 9, wartość = progress + 1
int osoby = sbOsoby.getProgress() + 1;
// zakres -20..40 → max = 60, wartość = progress - 20
int temperatura = sbTemp.getProgress() - 20;

Maksimum zmieniane z kodu (Arkusz_10)

Java
sbWiek.setMax(18);                 // np. po wybraniu „Pies”
tvWiek.setText(String.valueOf(sbWiek.getProgress()));  // bieżąca wartość mogła się zmniejszyć

Kolor z liczb

Java
tvPodglad.setBackgroundColor(Color.rgb(r, g, b));        // 0..255 każda
String hex = String.format("#%02X%02X%02X", r, g, b);    // np. "#FF8800"

Ćwiczenie natychmiastowe: w przykładzie zmień maksimum na 60 i ustaw progress="30". Czy napis „Rozmiar: 20” na starcie jest nadal prawdziwy? Popraw XML.

package com.example.egzamin;

import android.os.Bundle;
import android.widget.SeekBar;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        TextView tvWartosc = findViewById(R.id.tvWartosc);
        TextView tvPodglad = findViewById(R.id.tvPodglad);
        SeekBar sbRozmiar = findViewById(R.id.sbRozmiar);

        sbRozmiar.setOnSeekBarChangeListener(new SeekBar.OnSeekBarChangeListener() {
            @Override
            public void onProgressChanged(SeekBar seekBar, int progress, boolean fromUser) {
                // wywoływane przy każdym ruchu suwaka — tu jest cała logika
                tvWartosc.setText("Rozmiar: " + progress);
                tvPodglad.setTextSize(progress);   // rozmiar w sp
            }

            @Override
            public void onStartTrackingTouch(SeekBar seekBar) {
                // nieużywane, ale metoda musi istnieć
            }

            @Override
            public void onStopTrackingTouch(SeekBar seekBar) {
                // nieużywane
            }
        });
    }
}

4. Mikroćwiczenia

Ćwiczenie 8.1 — Specyfikacja suwaka

Arkusz_10: „Suwak … o wartości początkowej 0 i wartości maksymalnej 20”. Napisz XML.

Sprawdź odpowiedź

<SeekBar android:id="@+id/sbWiek" android:layout_width="0dp" android:layout_height="wrap_content" android:layout_weight="1" android:max="20" android:progress="0" /> — w rzędzie z napisami szerokość 0dp i waga 1.

Ćwiczenie 8.2 — this w klasie anonimowej

W onProgressChanged chcesz pokazać Toast. Popraw: Toast.makeText(this, "Max!", Toast.LENGTH_SHORT).show();

Sprawdź odpowiedź

Toast.makeText(MainActivity.this, "Max!", Toast.LENGTH_SHORT).show(); — w lambdzie this oznacza aktywność, w klasie anonimowej — obiekt tej klasy.

Ćwiczenie 8.3 — Przesunięcie zakresu

Suwak ma pozwolić wybrać liczbę godzin od 1 do 12. Jakie max ustawisz i jak odczytasz liczbę godzin?

Sprawdź odpowiedź

max="11", godziny = getProgress() + 1. Na starcie (progress 0) napis powinien pokazywać 1.

Ćwiczenie 8.4 — Zmiana maksimum

Suwak wieku ma wartość 15 i max 20. Użytkownik wybiera „Świnka morska” → setMax(9). Jaką wartość pokaże suwak i co trzeba zrobić z napisem obok?

Sprawdź odpowiedź

SeekBar sam obetnie wartość do 9 (i zwykle wywoła onProgressChanged). Dla pewności po setMax odśwież napis: tvWiek.setText(String.valueOf(sbWiek.getProgress()));.

Ćwiczenie 8.5 — Format HEX

Jaki tekst da String.format("#%02X%02X%02X", 255, 136, 0)? Co znaczy %02X?

Sprawdź odpowiedź

„#FF8800”. X — szesnastkowo wielkimi literami, 02 — minimum 2 znaki z zerem na początku (0 → „00”).

5. Zadanie prowadzone

Głośność z obrazem

⏱ ok. 35 min

Suwak w rzędzie z napisami (jak w Arkuszu_10), a obraz głośnika zależy od przedziału wartości.

Działanie: suwak 0..10, start 5. Napis obok: „<wartość>/10”. Obraz i opis: 0 → glosnik_cisza, „Wyciszono”; 1–6 → glosnik_cicho, „Cicho”; 7–10 → glosnik_glosno, „Głośno”.

Kroki:

  1. XML: tytuł, ImageView 200dp (start glosnik_cicho), rząd: „Głośność:” + SeekBar (0dp, waga 1, max 10, progress 5) + napis „5/10”; opis pod spodem.
  2. Java: listener z trzema metodami; w onProgressChanged wywołaj pokazGlosnosc(progress, seekBar.getMax()).
  3. pokazGlosnosc: napis + if / else if / else na przedziały.

Zasoby do zadania

Pobierz wszystkie: zasoby_b08-prowadzone.zip. Obrazy skopiuj do app/src/main/res/drawable (nazwy: małe litery, bez spacji i myślników).

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Przedziały sprawdzaj od najmniejszego: == 0, potem <= 6, a else obsłuży resztę.

Poziom 2 — konkretna wskazówka

Rząd z suwakiem: napisy wrap_content, suwak layout_width="0dp" + layout_weight="1", na rzędzie gravity="center_vertical".

Poziom 3 — pseudokod / struktura
Tekst
onProgressChanged(p): pokazGlosnosc(p, max)
pokazGlosnosc(p, max):
    napis ← p + "/" + max
    jeśli p == 0 → cisza, "Wyciszono"
    inaczej jeśli p <= 6 → cicho, "Cicho"
    inaczej → głośno, "Głośno"
Poziom 4 — fragment implementacji
Java
@Override
public void onProgressChanged(SeekBar seekBar, int progress, boolean fromUser) {
    pokazGlosnosc(progress, seekBar.getMax());
}

package com.example.egzamin;

import android.os.Bundle;
import android.widget.ImageView;
import android.widget.SeekBar;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private ImageView ivGlosnik;
    private TextView tvGlosnosc, tvOpis;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        ivGlosnik = findViewById(R.id.ivGlosnik);
        tvGlosnosc = findViewById(R.id.tvGlosnosc);
        tvOpis = findViewById(R.id.tvOpis);
        SeekBar sbGlosnosc = findViewById(R.id.sbGlosnosc);

        sbGlosnosc.setOnSeekBarChangeListener(new SeekBar.OnSeekBarChangeListener() {
            @Override
            public void onProgressChanged(SeekBar seekBar, int progress, boolean fromUser) {
                pokazGlosnosc(progress, seekBar.getMax());
            }

            @Override
            public void onStartTrackingTouch(SeekBar seekBar) {
            }

            @Override
            public void onStopTrackingTouch(SeekBar seekBar) {
            }
        });
    }

    private void pokazGlosnosc(int poziom, int maksimum) {
        tvGlosnosc.setText(poziom + "/" + maksimum);
        if (poziom == 0) {
            ivGlosnik.setImageResource(R.drawable.glosnik_cisza);
            tvOpis.setText("Wyciszono");
        } else if (poziom <= 6) {
            ivGlosnik.setImageResource(R.drawable.glosnik_cicho);
            tvOpis.setText("Cicho");
        } else {
            ivGlosnik.setImageResource(R.drawable.glosnik_glosno);
            tvOpis.setText("Głośno");
        }
    }
}

6. Zadanie samodzielne

Mieszalnik kolorów RGB

⏱ ok. 40 min

Trzy suwaki sterują kolorem prostokąta — wzorzec z desktopowego Arkusza_15 przeniesiony na telefon. Wymagany jeden obiekt nasłuchujący dla trzech suwaków.

  • Prostokąt podglądu (wys. 160dp, na całą szerokość), pod nim kod koloru w HEX, pogrubiony.
  • Trzy rzędy: litera (R, G, B), suwak 0..255 (start 255), wartość liczbowa w polu o stałej szerokości 40dp.
  • Każda zmiana któregokolwiek suwaka aktualizuje wszystkie trzy wartości, kolor prostokąta i kod HEX.
  • Tło ekranu Cornsilk #FFF8DC.

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Utwórz obiekt SeekBar.OnSeekBarChangeListener sluchacz = new …{…}; jako zmienną i przekaż go trzem suwakom.

Poziom 2 — konkretna wskazówka

W onProgressChanged nie korzystaj z parametru progress (nie wiesz, który suwak się ruszył) — odczytaj wszystkie trzy przez getProgress().

Poziom 3 — pseudokod / struktura
Tekst
odswiezKolor():
    r, g, b ← getProgress() trzech suwaków
    trzy napisy wartości
    podgląd.setBackgroundColor(Color.rgb(r, g, b))
    hex ← String.format("#%02X%02X%02X", r, g, b)
Poziom 4 — fragment implementacji
Java

    @Override public void onProgressChanged(SeekBar s, int p, boolean u) { odswiezKolor(); }
    @Override public void onStartTrackingTouch(SeekBar s) { }

package com.example.egzamin;

import android.graphics.Color;
import android.os.Bundle;
import android.widget.SeekBar;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private SeekBar sbR, sbG, sbB;
    private TextView tvWartR, tvWartG, tvWartB, tvPodglad, tvHex;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        sbR = findViewById(R.id.sbR);
        sbG = findViewById(R.id.sbG);
        sbB = findViewById(R.id.sbB);
        tvWartR = findViewById(R.id.tvWartR);
        tvWartG = findViewById(R.id.tvWartG);
        tvWartB = findViewById(R.id.tvWartB);
        tvPodglad = findViewById(R.id.tvPodglad);
        tvHex = findViewById(R.id.tvHex);

        // jeden obiekt nasłuchujący dla trzech suwaków
        SeekBar.OnSeekBarChangeListener sluchacz = new SeekBar.OnSeekBarChangeListener() {
            @Override
            public void onProgressChanged(SeekBar seekBar, int progress, boolean fromUser) {
                odswiezKolor();
            }

            @Override
            public void onStartTrackingTouch(SeekBar seekBar) {
            }

            @Override
            public void onStopTrackingTouch(SeekBar seekBar) {
            }
        };
        sbR.setOnSeekBarChangeListener(sluchacz);
        sbG.setOnSeekBarChangeListener(sluchacz);
        sbB.setOnSeekBarChangeListener(sluchacz);
    }

    private void odswiezKolor() {
        int r = sbR.getProgress();
        int g = sbG.getProgress();
        int b = sbB.getProgress();
        tvWartR.setText(String.valueOf(r));
        tvWartG.setText(String.valueOf(g));
        tvWartB.setText(String.valueOf(b));
        tvPodglad.setBackgroundColor(Color.rgb(r, g, b));
        tvHex.setText(String.format("#%02X%02X%02X", r, g, b));
    }
}

7. Zadanie w stylu INF.04

Podział rachunku z napiwkiem

⏱ ok. 45 min

Wykonaj aplikację mobilną obliczającą napiwek i kwotę przypadającą na osobę.

Krok 1–6: analiza polecenia. Zanim otworzysz Android Studio, wypisz na kartce (lub w komentarzu) odpowiedzi:
INTERFEJSCo musi znaleźć się na ekranie?
DANECo wpisuje / wybiera użytkownik?
ZDARZENIACo uruchamia działania?
LOGIKACo trzeba policzyć / sprawdzić / zmienić?
WYNIKCo aplikacja wyświetla lub zmienia?
WYGLĄDKolory, rozmiary, marginesy, rozkłady?
Porównaj swoją analizę z wzorcową
INTERFEJStytuł, pole kwoty, 2 rzędy (etykieta + suwak + wartość), przycisk, 3 napisy wyników, autor
DANEkwota (liczba dziesiętna), procent 0..30 (suwak), liczba osób 1..10 (suwak z przesunięciem)
ZDARZENIAzmiana każdego suwaka, kliknięcie „OBLICZ”
LOGIKAnapiwek = kwota·%/100; razem = kwota + napiwek; na osobę = razem / osoby; walidacja pustej i błędnej kwoty
WYNIK„Napiwek: x zł”, „Razem: x zł”, „Na osobę: x zł” (2 miejsca), etykiety suwaków na żywo
WYGLĄDtło #E0F2F1; tytuł #00695C biały; rzędy suwaków; przycisk #00695C wyśrodkowany; „Na osobę” 24sp pogrubiony

Elementy aplikacji:

  • Napis „Podział rachunku”.
  • Pole edycyjne z podpowiedzią „Kwota rachunku (zł)” przyjmujące liczby dziesiętne.
  • Rząd: napis „Napiwek:”, suwak (0..30, wartość początkowa 10), napis z wartością „10%”.
  • Rząd: napis „Liczba osób:”, suwak, napis z wartością „1”. Suwak pozwala wybrać liczbę osób od 1 do 10.
  • Przycisk „OBLICZ”.
  • Napisy: „Napiwek: 0,00 zł”, „Razem: 0,00 zł”, „Na osobę: 0,00 zł”.
  • Napis „Autor: ”, dalej numer zdającego.

Działanie aplikacji:

  • Przesuwanie suwaków na bieżąco zmienia napisy obok nich („15%”, „4”) oraz przelicza wyniki.
  • „OBLICZ” przelicza wyniki (np. po zmianie kwoty).
  • napiwek = kwota · procent / 100; razem = kwota + napiwek; na osobę = razem / liczba osób. Wyniki z dwoma miejscami po przecinku.
  • Gdy pole kwoty jest puste: pierwszy napis „Podaj kwotę rachunku”, pozostałe puste. Gdy kwota jest niepoprawna: „Niepoprawna kwota”. Aplikacja się nie zamyka.

Założenia aplikacji:

  • Interfejs w XML; rozkład liniowy pionowy z zagnieżdżonymi rozkładami poziomymi dla suwaków i ich napisów; suwaki zajmują całą wolną szerokość rzędu.
  • Tło strony #E0F2F1; tytuł: tło #00695C, biała czcionka, największa, marginesy wewnętrzne 10. Przycisk wyśrodkowany, tło #00695C, biała czcionka.
  • Napis „Na osobę” pogrubiony, większy niż pozostałe wyniki. Wyniki wyśrodkowane.
  • Oba suwaki obsługiwane przez jeden obiekt nasłuchujący. Obliczenia w jednej metodzie.

java/com/example/egzamin/MainActivity.java
package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.EditText;
import android.widget.SeekBar;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private static final int MIN_OSOB = 1;   // SeekBar zaczyna od 0, więc przesuwamy zakres o 1

    private EditText etKwota;
    private SeekBar sbNapiwek, sbOsoby;
    private TextView tvProcent, tvOsoby, tvNapiwek, tvRazem, tvNaOsobe;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        etKwota = findViewById(R.id.etKwota);
        sbNapiwek = findViewById(R.id.sbNapiwek);
        sbOsoby = findViewById(R.id.sbOsoby);
        tvProcent = findViewById(R.id.tvProcent);
        tvOsoby = findViewById(R.id.tvOsoby);
        tvNapiwek = findViewById(R.id.tvNapiwek);
        tvRazem = findViewById(R.id.tvRazem);
        tvNaOsobe = findViewById(R.id.tvNaOsobe);
        Button btnOblicz = findViewById(R.id.btnOblicz);

        SeekBar.OnSeekBarChangeListener sluchacz = new SeekBar.OnSeekBarChangeListener() {
            @Override
            public void onProgressChanged(SeekBar seekBar, int progress, boolean fromUser) {
                tvProcent.setText(sbNapiwek.getProgress() + "%");
                tvOsoby.setText(String.valueOf(liczbaOsob()));
                przelicz();
            }

            @Override
            public void onStartTrackingTouch(SeekBar seekBar) {
            }

            @Override
            public void onStopTrackingTouch(SeekBar seekBar) {
            }
        };
        sbNapiwek.setOnSeekBarChangeListener(sluchacz);
        sbOsoby.setOnSeekBarChangeListener(sluchacz);
        btnOblicz.setOnClickListener(v -> przelicz());
    }

    private int liczbaOsob() {
        return sbOsoby.getProgress() + MIN_OSOB;
    }

    private void przelicz() {
        String tekst = etKwota.getText().toString().trim().replace(',', '.');
        if (tekst.isEmpty()) {
            tvNapiwek.setText("Podaj kwotę rachunku");
            tvRazem.setText("");
            tvNaOsobe.setText("");
            return;
        }
        try {
            double kwota = Double.parseDouble(tekst);
            double napiwek = kwota * sbNapiwek.getProgress() / 100.0;
            double razem = kwota + napiwek;
            double naOsobe = razem / liczbaOsob();
            tvNapiwek.setText(String.format("Napiwek: %.2f zł", napiwek));
            tvRazem.setText(String.format("Razem: %.2f zł", razem));
            tvNaOsobe.setText(String.format("Na osobę: %.2f zł", naOsobe));
        } catch (NumberFormatException e) {
            tvNapiwek.setText("Niepoprawna kwota");
            tvRazem.setText("");
            tvNaOsobe.setText("");
        }
    }
}
