Blok 15. Tryb egzaminacyjny III: od pustego projektu do oddania

Faza III — tryb egzaminacyjny W trakcie

Egzamin końcowy kursu: dwa zadania wykonywane od zera (nowy projekt, bez kopiowania z wcześniejszych lekcji), pełna procedura oddania i samoocena wg kryteriów podobnych do egzaminacyjnych.

1. Cel

Po wykonaniu tego bloku będziesz potrafił:

  • utworzyć od zera projekt i zbudować w nim kompletną aplikację bez korzystania z wcześniejszego kodu,
  • łączyć 4–5 wzorców (lista, radio, suwak, pola wyboru, walidacja, okno komunikatu, losowanie, liczniki) w jednej aplikacji,
  • przygotować komplet plików do oddania w wymaganym czasie,
  • ocenić własne rozwiązanie wg kryteriów i wskazać tematy do powtórki przed egzaminem.
Plan czasu (4 × 45 min = 180 min)
Przypomnienie (workflow + oddanie)10 min
Przykład (samoocena)10 min
Mikroćwiczenia (sprint)15 min
Rozgrzewka od zera20 min
Próbny egzamin — zadanie 160 min
Próbny egzamin — zadanie 255 min

Razem180 min

Powiązanie z arkuszami: zadanie 1: lista + pola radio + suwak + pola wyboru + walidacja tekstu + okno komunikatu (Arkusz_10 i Arkusz_01 w nowej kombinacji); zadanie 2: losowanie i liczniki (Arkusz_12) + suwak z przesunięciem (07/10) + lista historii (05) + algorytm najdłuższej serii. Oba wymagają transferu.

2. Krótkie przypomnienie: workflow egzaminacyjny

Workflow egzaminacyjny — 10 kroków

KrokCo robiszCzas (z ~60 min)
1Przeczytaj całe zadanie (także założenia i ostatnią stronę)3 min
2Wypisz elementy interfejsu (kolejność z góry na dół, rzędy)2 min
3Wypisz dane wejściowe1 min
4Wypisz zdarzenia (co klika / przesuwa użytkownik)1 min
5Wypisz logikę (wzory, warunki, cykle, liczniki)2 min
6Wypisz wyniki (co i gdzie się zmienia)1 min

8Dodaj logikę w Javie (zdarzenie po zdarzeniu, uruchamiając po każdym)20 min
9Przetestuj każdy punkt „Działanie aplikacji”, zrób zrzuty7 min
10Porównaj punkt po punkcie ze specyfikacją; spakuj mobilna.zip, skopiuj pliki8 min

Zasada: najpierw działający szkielet, potem szczegóły. Aplikacja, która się uruchamia i realizuje 80% wymagań, daje więcej punktów niż „prawie gotowa”, która się nie kompiluje. Po każdej większej zmianie — uruchom.

Od pustego projektu — lista startowa (5 minut)

  1. New Project → Empty Views Activity, Java, pakiet np. com.example.egzamin.
  2. activity_main.xml → tryb Code → korzeń LinearLayout (vertical, @+id/main).
  3. MainActivity.java → usuń linie EdgeToEdge/ViewCompat (albo zostaw @+id/main).
  4. Obrazy z archiwum → res/drawable (nazwy: małe litery, bez myślników).
  5. Uruchom pusty projekt w emulatorze (sprawdzisz, że środowisko działa, zanim napiszesz 200 linii).

3. Przykład: analiza specyfikacji krok po kroku

Samoocena — jak punktuje się część mobilną (model kursowy). Egzaminatorzy oceniają rezultaty według kryteriów z arkusza; poniższa lista naśladuje ich charakter: każdy punkt to konkretne, sprawdzalne zdanie. Po każdym próbnym egzaminie przejdź ją i policz punkty.

Przy liczeniu bądź surowy: „prawie działa” = 0 pkt za dany punkt. Każdy utracony punkt zapisz jako temat do powtórki i wróć do odpowiedniego bloku (mapa pokrycia w ANALIZA_INF04_MOBILE.md).

4. Mikroćwiczenia: sprint z pamięci

Ćwiczenie 15.1 — Sprint 1 (3 min): odmiana

Napisz metodę zwracającą „łyżeczka / łyżeczki / łyżeczek” dla n = 0..5.

Sprawdź odpowiedź
Java
private String odmianaLyzeczki(int n) {
    if (n == 1) return "łyżeczka";
    if (n >= 2 && n <= 4) return "łyżeczki";
    return "łyżeczek";
}

Ćwiczenie 15.2 — Sprint 2 (4 min): walidacja „GG:MM”

Metoda boolean czyPoprawnaGodzina(String t): długość 5, dwukropek na pozycji 2, godziny 0–23, minuty 0–59.

Sprawdź odpowiedź
Java
private boolean czyPoprawnaGodzina(String tekst) {
    if (tekst.length() != 5 || tekst.charAt(2) != ':') return false;
    try {
        int g = Integer.parseInt(tekst.substring(0, 2));
        int m = Integer.parseInt(tekst.substring(3));
        return g >= 0 && g <= 23 && m >= 0 && m <= 59;
    } catch (NumberFormatException e) {
        return false;
    }
}

Ćwiczenie 15.3 — Sprint 3 (4 min): najdłuższa seria

Masz tablicę rzutów int[] r (0 = orzeł, 1 = reszka). Policz najdłuższą serię orłów pod rząd.

Sprawdź odpowiedź
Java
int biezaca = 0, najdluzsza = 0;
for (int x : r) {
    if (x == 0) {
        biezaca++;
        najdluzsza = Math.max(najdluzsza, biezaca);
    } else {
        biezaca = 0;
    }
}

Ćwiczenie 15.4 — Sprint 4 (4 min): cena z dodatkami

Cena bazowa z tablicy ceny[wybrana], rozmiar średni +2, duży +4, każde zaznaczone pole wyboru dodaje swoją kwotę. Zapisz fragment liczący.

Sprawdź odpowiedź

Zmienna int cena = ceny[wybrana]; → if (id == R.id.rbSrednia) cena += 2; else if (id == R.id.rbDuza) cena += 4; → if (cbMleko.isChecked()) cena += 2; itd. Kolejność dodawania nie ma znaczenia, ważne, by każdy warunek był osobny (if, nie else if) dla pól wyboru.

5. Zadanie prowadzone (rozgrzewka)

Rozgrzewka od zera: generator hasła (20 min)

⏱ ok. 20 min

Nowy, pusty projekt i stoper w ręku. Pomysł pochodzi z desktopowego Arkusza_04 (generowanie hasła z opcjami) — tu w wersji mobilnej: suwak długości i pola wyboru zestawów znaków.

  • Suwak długości hasła od 4 do 16 (start 8), wartość obok suwaka.
  • Pola wyboru: „Wielkie litery” (domyślnie zaznaczone), „Cyfry”, „Znaki specjalne” (!@#$%^&*()_+-=). Małe litery są zawsze w puli.
  • GENERUJ: hasło o wybranej długości, każdy znak losowany z puli złożonej z zaznaczonych zestawów; wynik w polu na dole (tło #ECEFF1, 24sp).
  • Zestawy znaków przechowuj jako stałe typu napisowego.

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Zbuduj napis pula z małych liter i dopisuj do niego kolejne zestawy w osobnych if (pola wyboru są niezależne).

Poziom 2 — konkretna wskazówka

Losowy znak: pula.charAt(losowanie.nextInt(pula.length())). Suwak: max="12", progress="4", długość = progress + 4.

Poziom 3 — pseudokod / struktura
Tekst
generujHaslo(d): pula ← małe; +wielkie jeśli zaznaczone; +cyfry…; +specjalne…
                 haslo ← ""; powtórz d razy: haslo += losowy znak z puli
                 zwróć haslo
Poziom 4 — fragment implementacji
Java
private String generujHaslo(int dlugosc) {
    String pula = MALE;
    if (cbWielkie.isChecked()) pula += WIELKIE;
    if (cbCyfry.isChecked()) pula += CYFRY;
    if (cbSpecjalne.isChecked()) pula += SPECJALNE;
    String haslo = "";
    for (int i = 0; i < dlugosc; i++) {
        haslo += pula.charAt(losowanie.nextInt(pula.length()));
    }
    return haslo;
}

package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.CheckBox;
import android.widget.SeekBar;
import android.widget.TextView;

import java.util.Random;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private static final int MIN_DLUGOSC = 4;   // suwak 0..12 → długość 4..16
    private static final String MALE = "abcdefghijklmnopqrstuvwxyz";
    private static final String WIELKIE = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";
    private static final String CYFRY = "0123456789";
    private static final String SPECJALNE = "!@#$%^&*()_+-=";

    private final Random losowanie = new Random();
    private SeekBar sbDlugosc;
    private TextView tvDlugosc, tvHaslo;
    private CheckBox cbWielkie, cbCyfry, cbSpecjalne;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        sbDlugosc = findViewById(R.id.sbDlugosc);
        tvDlugosc = findViewById(R.id.tvDlugosc);
        tvHaslo = findViewById(R.id.tvHaslo);
        cbWielkie = findViewById(R.id.cbWielkie);
        cbCyfry = findViewById(R.id.cbCyfry);
        cbSpecjalne = findViewById(R.id.cbSpecjalne);
        Button btnGeneruj = findViewById(R.id.btnGeneruj);

        sbDlugosc.setOnSeekBarChangeListener(new SeekBar.OnSeekBarChangeListener() {
            @Override
            public void onProgressChanged(SeekBar seekBar, int progress, boolean fromUser) {
                tvDlugosc.setText(String.valueOf(progress + MIN_DLUGOSC));
            }

            @Override
            public void onStartTrackingTouch(SeekBar seekBar) {
            }

            @Override
            public void onStopTrackingTouch(SeekBar seekBar) {
            }
        });

        btnGeneruj.setOnClickListener(v -> tvHaslo.setText(generujHaslo(sbDlugosc.getProgress() + MIN_DLUGOSC)));
    }

    // każdy zaznaczony zestaw dokłada swoje znaki do puli, z której losujemy
    private String generujHaslo(int dlugosc) {
        String pula = MALE;
        if (cbWielkie.isChecked()) {
            pula += WIELKIE;
        }
        if (cbCyfry.isChecked()) {
            pula += CYFRY;
        }
        if (cbSpecjalne.isChecked()) {
            pula += SPECJALNE;
        }
        String haslo = "";
        for (int i = 0; i < dlugosc; i++) {
            haslo += pula.charAt(losowanie.nextInt(pula.length()));
        }
        return haslo;
    }
}

6. Próbny egzamin — zadanie 1

Próbny egzamin 5: Kawiarnia (60 min, od pustego projektu)

⏱ ok. 60 min

Warunki próbnego egzaminu: pracuj bez zaglądania do wcześniejszych bloków i własnych projektów (wolno: ta treść, zasoby, dokumentacja Android Studio). Zmierz czas. Podpowiedzi otwieraj dopiero po upływie czasu albo gdy zupełnie utkniesz — i zapisz, z których skorzystałeś. Na koniec: zrzuty mobile1.png…, mobilna.zip, kopie plików źródłowych, srodowisko.txt.

Za pomocą środowiska programistycznego wykonaj aplikację mobilną do zamawiania kawy i uruchom ją w emulatorze. Do wykonania zadania wykorzystaj obraz z archiwum zasoby_b15-egzE.zip. Rozpocznij od nowego, pustego projektu.

Krok 1–6: analiza polecenia. Zanim otworzysz Android Studio, wypisz na kartce (lub w komentarzu) odpowiedzi:
INTERFEJSCo musi znaleźć się na ekranie?
DANECo wpisuje / wybiera użytkownik?
ZDARZENIACo uruchamia działania?
LOGIKACo trzeba policzyć / sprawdzić / zmienić?
WYNIKCo aplikacja wyświetla lub zmienia?
WYGLĄDKolory, rozmiary, marginesy, rozkłady?
Porównaj swoją analizę z wzorcową
INTERFEJStytuł, obraz, „Wybierz kawę:”, lista 4 kaw, „Wybrano”, 3 pola radio w rzędzie, rząd cukru (napis, suwak, wartość), 2 pola wyboru, pole godziny, przycisk, autor
DANEkawa (lista), rozmiar (radio), cukier 0..5, dodatki, godzina tekstem
ZDARZENIAklik elementu listy, zmiana suwaka, ZAMÓW
LOGIKAcena bazowa z tablicy + rozmiar + dodatki; odmiana „łyżeczka”; walidacja: kawa wybrana, godzina GG:MM (0–23, 0–59)
WYNIK„Wybrano: …”, „n łyżeczek”, okno „Zamówienie” z podsumowaniem i ceną, Toast przy błędach
WYGLĄDtło #FBF6EE; tytuł #4E342E biały; obraz 110dp wyśrodkowany; separator listy #8D6E63; przycisk #4E342E wyśrodkowany

Elementy aplikacji:

  • Napis „Kawiarnia”.
  • Obraz kawa.
  • Napis „Wybierz kawę:” i lista: „Espresso — 8 zł”, „Latte — 12 zł”, „Cappuccino — 11 zł”, „Americano — 9 zł”.
  • Napis „Wybrano: —”.
  • Trzy pola radio w jednym rzędzie: „Mała” (domyślnie zaznaczone), „Średnia (+2 zł)”, „Duża (+4 zł)”.
  • Rząd: napis „Cukier:”, suwak (0–5, początkowo 0), napis „0 łyżeczek”.
  • Pola wyboru „Mleko roślinne (+2 zł)” i „Na wynos (+1 zł)”.
  • Pole edycyjne z podpowiedzią „Godzina odbioru (GG:MM)”.
  • Przycisk „ZAMÓW”.
  • Napis „Autor: ”, dalej numer zdającego.

Działanie aplikacji:

  • Kliknięcie kawy na liście wyświetla „Wybrano: <nazwa>”.
  • Przesuwanie suwaka wyświetla liczbę łyżeczek z poprawną odmianą: „0 łyżeczek”, „1 łyżeczka”, „2 łyżeczki” … „5 łyżeczek”.
  • Po wybraniu „ZAMÓW”:
    • gdy nie wybrano kawy — Toast „Wybierz kawę”;
    • gdy godzina nie ma postaci GG:MM z godziną 00–23 i minutami 00–59 — Toast „Podaj godzinę w formacie GG:MM”;
    • w przeciwnym razie okno komunikatu z tytułem „Zamówienie” i treścią: nazwa kawy, rozmiar, cukier („n łyżeczek cukru” z odmianą), „mleko roślinne” / „mleko zwykłe”, „na wynos” / „na miejscu”, „odbiór <GG:MM>”, „do zapłaty: <cena> zł” — rozdzielone przecinkami.
  • Cena = cena kawy + dopłata za rozmiar + dopłaty za zaznaczone pola wyboru.

Założenia aplikacji:

  • Interfejs w XML; rozkład liniowy pionowy z zagnieżdżonymi rozkładami poziomymi (pola radio, cukier).
  • Tło strony #FBF6EE. Tytuł: tło #4E342E, biała czcionka, największa, marginesy wewnętrzne 10.
  • Obraz: wysokość 110, wyśrodkowany. Lista: wysokość dopasowana do liczby elementów, separator #8D6E63 widoczny.
  • Przycisk wyśrodkowany, tło #4E342E, biała czcionka.
  • Nazwy i ceny kaw w tablicach. Walidacja godziny i odmiana w osobnych metodach.

Zasoby do zadania

Pobierz wszystkie: zasoby_b15-egzE.zip. Obrazy skopiuj do app/src/main/res/drawable (nazwy: małe litery, bez spacji i myślników).

package com.example.egzamin;

import android.os.Bundle;
import android.widget.ArrayAdapter;
import android.widget.Button;
import android.widget.CheckBox;
import android.widget.EditText;
import android.widget.ListView;
import android.widget.RadioGroup;
import android.widget.SeekBar;
import android.widget.TextView;
import android.widget.Toast;

import androidx.appcompat.app.AlertDialog;
import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private final String[] kawy = {"Espresso", "Latte", "Cappuccino", "Americano"};
    private final int[] ceny = {8, 12, 11, 9};
    private int wybranaKawa = -1;

    private TextView tvWybrano, tvCukier;
    private RadioGroup rgRozmiar;
    private SeekBar sbCukier;
    private CheckBox cbMleko, cbWynos;
    private EditText etGodzina;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        ListView lvKawy = findViewById(R.id.lvKawy);
        tvWybrano = findViewById(R.id.tvWybrano);
        tvCukier = findViewById(R.id.tvCukier);
        rgRozmiar = findViewById(R.id.rgRozmiar);
        sbCukier = findViewById(R.id.sbCukier);
        cbMleko = findViewById(R.id.cbMleko);
        cbWynos = findViewById(R.id.cbWynos);
        etGodzina = findViewById(R.id.etGodzina);
        Button btnZamow = findViewById(R.id.btnZamow);

        String[] pozycje = new String[kawy.length];
        for (int i = 0; i < kawy.length; i++) {
            pozycje[i] = kawy[i] + " — " + ceny[i] + " zł";
        }
        lvKawy.setAdapter(new ArrayAdapter<>(this, android.R.layout.simple_list_item_1, pozycje));

        lvKawy.setOnItemClickListener((parent, view, position, id) -> {
            wybranaKawa = position;
            tvWybrano.setText("Wybrano: " + kawy[position]);
        });

        sbCukier.setOnSeekBarChangeListener(new SeekBar.OnSeekBarChangeListener() {
            @Override
            public void onProgressChanged(SeekBar seekBar, int progress, boolean fromUser) {
                tvCukier.setText(progress + " " + odmianaLyzeczki(progress));
            }

            @Override
            public void onStartTrackingTouch(SeekBar seekBar) {
            }

            @Override
            public void onStopTrackingTouch(SeekBar seekBar) {
            }
        });

        btnZamow.setOnClickListener(v -> zamow());
    }

    // 1 łyżeczka, 2-4 łyżeczki, 0 i 5 łyżeczek
    private String odmianaLyzeczki(int n) {
        if (n == 1) {
            return "łyżeczka";
        } else if (n >= 2 && n <= 4) {
            return "łyżeczki";
        }
        return "łyżeczek";
    }

    private boolean czyPoprawnaGodzina(String tekst) {
        if (tekst.length() != 5 || tekst.charAt(2) != ':') {
            return false;
        }
        try {
            int godziny = Integer.parseInt(tekst.substring(0, 2));
            int minuty = Integer.parseInt(tekst.substring(3));
            return godziny >= 0 && godziny <= 23 && minuty >= 0 && minuty <= 59;
        } catch (NumberFormatException e) {
            return false;
        }
    }

    private void zamow() {
        if (wybranaKawa == -1) {
            Toast.makeText(this, "Wybierz kawę", Toast.LENGTH_SHORT).show();
            return;
        }
        String godzina = etGodzina.getText().toString().trim();
        if (!czyPoprawnaGodzina(godzina)) {
            Toast.makeText(this, "Podaj godzinę w formacie GG:MM", Toast.LENGTH_SHORT).show();
            return;
        }
        int cena = ceny[wybranaKawa];
        String rozmiar = "mała";
        int zaznaczony = rgRozmiar.getCheckedRadioButtonId();
        if (zaznaczony == R.id.rbSrednia) {
            rozmiar = "średnia";
            cena += 2;
        } else if (zaznaczony == R.id.rbDuza) {
            rozmiar = "duża";
            cena += 4;
        }
        if (cbMleko.isChecked()) {
            cena += 2;
        }
        if (cbWynos.isChecked()) {
            cena += 1;
        }
        int cukier = sbCukier.getProgress();
        String tresc = kawy[wybranaKawa] + ", " + rozmiar + ", "
                + cukier + " " + odmianaLyzeczki(cukier) + " cukru, "
                + (cbMleko.isChecked() ? "mleko roślinne" : "mleko zwykłe") + ", "
                + (cbWynos.isChecked() ? "na wynos" : "na miejscu") + ", "
                + "odbiór " + godzina + ", do zapłaty: " + cena + " zł";
        new AlertDialog.Builder(this)
                .setTitle("Zamówienie")
                .setMessage(tresc)
                .setPositiveButton("OK", null)
                .show();
    }
}

Elementy aplikacji:

  • Napis „Seria rzutów monetą”.
  • Obraz monety — w stanie początkowym pytajnik.
  • Rząd: napis „Liczba rzutów:”, suwak, napis z wartością (początkowo „1”). Suwak pozwala wybrać od 1 do 20.
  • Przyciski „RZUĆ SERIĘ” i „RESET” obok siebie.
  • Napis „Rzuty: 0 | Orły: 0 | Reszki: 0”.
  • Napis „Najdłuższa seria orłów: 0”.
  • Lista historii serii.
  • Napis „Autor: ”, dalej numer zdającego.

Działanie aplikacji:

  • „RZUĆ SERIĘ” wykonuje tyle losowych rzutów monetą (orzeł / reszka, z równym prawdopodobieństwem), ile wskazuje suwak.
  • Po serii: obraz pokazuje wynik ostatniego rzutu (moneta_orzel / moneta_reszka); napis statystyk pokazuje łączne liczby rzutów, orłów i reszek od początku gry; na końcu listy pojawia się wpis „Seria <n>: rzuty <x>, orły <y>, reszki <z>”.
  • „Najdłuższa seria orłów” to największa liczba orłów wyrzuconych pod rząd we wszystkich dotychczasowych rzutach — seria może przechodzić z jednego kliknięcia na następne.
  • „RESET” zeruje wszystkie liczniki i serie, czyści listę, przywraca obraz pytajnik i ustawia suwak na 1.

Założenia aplikacji:

  • Interfejs w XML; rozkład liniowy pionowy z zagnieżdżonymi rozkładami poziomymi.
  • Tło strony #EFEBE9. Tytuł: tło #795548, biała czcionka, największa, wyśrodkowana, marginesy wewnętrzne 10.
  • Obraz: wysokość 140, widoczny w całości. Przyciski równej szerokości: „RZUĆ SERIĘ” tło #795548, „RESET” tło #9E9E9E, biała czcionka.
  • Separator listy #795548, widoczny. Lista wypełnia wolne miejsce.
  • Rzucanie serią w osobnej metodzie przyjmującej liczbę rzutów.

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Stan gry: orly, reszki, biezacaSeriaOrlow, najdluzszaSeria (pola klasy) + lista historii. Seria „przechodzi między kliknięciami”, więc bieżąca seria nie może być zmienną lokalną w metodzie.

Poziom 2 — konkretna wskazówka

Orzeł: biezacaSeriaOrlow++ i najdluzszaSeria = Math.max(najdluzszaSeria, biezacaSeriaOrlow). Reszka: biezacaSeriaOrlow = 0.

Tekst

resetuj(): wszystkie liczniki 0; clear; notify; pytajnik; setProgress(0); napisy

package com.example.egzamin;

import android.os.Bundle;
import android.widget.ArrayAdapter;
import android.widget.Button;
import android.widget.ImageView;
import android.widget.ListView;
import android.widget.SeekBar;
import android.widget.TextView;

import java.util.ArrayList;
import java.util.Random;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private static final int ORZEL = 0;

    private final Random losowanie = new Random();
    private final ArrayList<String> historia = new ArrayList<>();
    private ArrayAdapter<String> adapter;

    private int orly = 0;
    private int reszki = 0;
    private int biezacaSeriaOrlow = 0;
    private int najdluzszaSeria = 0;

    private ImageView ivMoneta;
    private SeekBar sbLiczba;
    private TextView tvLiczba, tvStatystyka, tvSeria;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        ivMoneta = findViewById(R.id.ivMoneta);
        sbLiczba = findViewById(R.id.sbLiczba);
        tvLiczba = findViewById(R.id.tvLiczba);
        tvStatystyka = findViewById(R.id.tvStatystyka);
        tvSeria = findViewById(R.id.tvSeria);
        ListView lvHistoria = findViewById(R.id.lvHistoria);
        Button btnRzuc = findViewById(R.id.btnRzuc);
        Button btnReset = findViewById(R.id.btnReset);

        adapter = new ArrayAdapter<>(this, android.R.layout.simple_list_item_1, historia);
        lvHistoria.setAdapter(adapter);

        sbLiczba.setOnSeekBarChangeListener(new SeekBar.OnSeekBarChangeListener() {
            @Override
            public void onProgressChanged(SeekBar seekBar, int progress, boolean fromUser) {
                tvLiczba.setText(String.valueOf(progress + 1));
            }

            @Override
            public void onStartTrackingTouch(SeekBar seekBar) {
            }

            @Override
            public void onStopTrackingTouch(SeekBar seekBar) {
            }
        });

        btnRzuc.setOnClickListener(v -> rzucSerie(sbLiczba.getProgress() + 1));
        btnReset.setOnClickListener(v -> resetuj());
    }

    private void rzucSerie(int liczbaRzutow) {
        int orlyWSerii = 0;
        int ostatni = ORZEL;
        for (int i = 0; i < liczbaRzutow; i++) {
            ostatni = losowanie.nextInt(2);
            if (ostatni == ORZEL) {
                orly++;
                orlyWSerii++;
                biezacaSeriaOrlow++;
                najdluzszaSeria = Math.max(najdluzszaSeria, biezacaSeriaOrlow);
            } else {
                reszki++;
                biezacaSeriaOrlow = 0;
            }
        }
        ivMoneta.setImageResource(ostatni == ORZEL ? R.drawable.moneta_orzel : R.drawable.moneta_reszka);
        historia.add("Seria " + (historia.size() + 1) + ": rzuty " + liczbaRzutow
                + ", orły " + orlyWSerii + ", reszki " + (liczbaRzutow - orlyWSerii));
        adapter.notifyDataSetChanged();
        pokazStatystyki();
    }

    private void pokazStatystyki() {
        tvStatystyka.setText("Rzuty: " + (orly + reszki) + " | Orły: " + orly + " | Reszki: " + reszki);
        tvSeria.setText("Najdłuższa seria orłów: " + najdluzszaSeria);
    }

    private void resetuj() {
        orly = 0;
        reszki = 0;
        biezacaSeriaOrlow = 0;
        najdluzszaSeria = 0;
        historia.clear();
        adapter.notifyDataSetChanged();
        ivMoneta.setImageResource(R.drawable.pytajnik);
        sbLiczba.setProgress(0);
        pokazStatystyki();
    }
}
