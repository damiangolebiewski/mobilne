Blok 1. Start: projekt, emulator i pierwszy ekran ze specyfikacji

Faza I — wyrównanie W trakcie

Tworzysz projekt Empty Views Activity w Javie, budujesz ekran z LinearLayout i TextView według opisu, uruchamiasz go w emulatorze i przygotowujesz pliki tak jak na egzaminie.

1. Cel

Po wykonaniu tego bloku będziesz potrafił:

  • utworzyć projekt Empty Views Activity w języku Java i uruchomić go w emulatorze,
  • wskazać pliki, które oddaje się na egzaminie: activity_main.xml, MainActivity.java, mobilna.zip,
  • zbudować ekran w pionowym LinearLayout z napisów o podanych kolorach, rozmiarach i wyrównaniu,
  • przeanalizować polecenie według 6 pytań: INTERFEJS, DANE, ZDARZENIA, LOGIKA, WYNIK, WYGLĄD.

2. Krótkie przypomnienie

Nowy projekt — zawsze tak samo

  1. File → New → New Project → Empty Views Activity. Uwaga: szablon „Empty Activity” tworzy projekt Compose — bez pliku XML, niezgodny z wymaganiem arkuszy.
  2. Name: Egzamin, Package name: com.example.egzamin, Language: Java, Minimum SDK: API 24.
  3. Finish i poczekaj, aż skończy się synchronizacja Gradle (pasek postępu na dole okna).
  4. Uruchom emulator (Device Manager) i aplikację: zielony trójkąt ▶ lub Shift+F10.

Upraszczamy szablon

Nowe Android Studio generuje w onCreate linie EdgeToEdge.enable(this) i ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), …). W tym kursie usuwamy je (razem z nieużywanymi importami) — kod jest krótszy, a padding ustawiony w XML działa tak, jak opisuje arkusz:

MainActivity.java — wersja kursowa
public class MainActivity extends AppCompatActivity {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
    }
}

Jeśli zostawisz linie z ViewCompat…findViewById(R.id.main), korzeń układu musi mieć android:id="@+id/main". Po zamianie korzenia na LinearLayout bez tego ID aplikacja zamknie się zaraz po starcie.

4. Mikroćwiczenia

Ćwiczenie 1.1 — Tytuł ze specyfikacji

Specyfikacja: „Napis «Wizyta u weterynarza» czcionką większą niż pozostałe, kolor tła SeaGreen (#2E8B57), marginesy wewnętrzne 10”. Napisz sam element TextView.

Sprawdź odpowiedź
XML
<TextView
    android:id="@+id/tvTytul"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:text="Wizyta u weterynarza"
    android:textSize="28sp"
    android:background="#2E8B57"
    android:padding="10dp" />

„Marginesy wewnętrzne” = padding. Szerokość match_parent, bo na zrzutach tło tytułu sięga krawędzi.

Ćwiczenie 1.2 — match_parent czy wrap_content?

Dwa napisy mają tło #FFD700. Pierwszy ma layout_width="wrap_content", drugi match_parent. Który będzie miał żółty pasek na całą szerokość ekranu? Który trzeba wybrać, gdy arkusz mówi „pola rozciągnięte na całą szerokość ekranu”?

Sprawdź odpowiedź

Drugi (match_parent). Wymaganie „na całą szerokość” (Arkusze 01, 07, 12) zawsze oznacza match_parent.

Ćwiczenie 1.3 — gravity czy layout_gravity?

Napis ma layout_width="match_parent". Chcesz, aby tekst był na środku. Który atrybut zadziała: android:gravity="center" czy android:layout_gravity="center"? A jeśli napis ma wrap_content?

Sprawdź odpowiedź
  • match_parent → element zajmuje całą szerokość, więc trzeba wyśrodkować treść: gravity="center".
  • wrap_content → element jest wąski, więc trzeba przesunąć cały element w rodzicu: layout_gravity="center" (lub center_horizontal).

Zapamiętaj: gravity = treść w środku mnie; layout_gravity = ja w rodzicu.

Ćwiczenie 1.4 — Znajdź 4 błędy

XML
<TextView
    android:layout_width="match_parent"
    android:text="Cena: 10 zł"
    android:textSize="20"
    android:textColor="008080"
    android:padding="10" />
Sprawdź odpowiedź
  1. brak android:layout_height (błąd budowania),
  2. textSize="20" → 20sp,
  3. textColor="008080" → #008080,
  4. padding="10" → 10dp.

Ćwiczenie 1.5 — Analiza polecenia

Przeczytaj fragment: „Aplikacja wyświetla napis «Kantor» (tło #1D4F91, biała czcionka, największa), pole edycyjne z podpowiedzią «Kwota w PLN», przycisk «PRZELICZ». Po wybraniu przycisku pod nim wyświetla się «<kwota> PLN = <wynik> EUR», kurs 4,30.” Uzupełnij tabelę: INTERFEJS, DANE, ZDARZENIA, LOGIKA, WYNIK, WYGLĄD.

Sprawdź odpowiedź
INTERFEJSTextView (tytuł), EditText, Button, TextView (wynik)
DANEkwota wpisana w polu
ZDARZENIAkliknięcie „PRZELICZ”
LOGIKAwynik = kwota / 4,30
WYNIKtekst „<kwota> PLN = <wynik> EUR” pod przyciskiem
WYGLĄDtytuł: tło #1D4F91, biała czcionka, największy rozmiar

5. Zadanie prowadzone

Profil ucznia

⏱ ok. 35 min

Zbuduj ekran profilu. Wykonuj kroki po kolei i po każdym kroku uruchamiaj aplikację — tak szybciej zauważysz błąd.

Kroki:

  1. Utwórz nowy projekt Empty Views Activity (Java) i uprość onCreate (usuń EdgeToEdge i ViewCompat).
  2. W activity_main.xml zamień korzeń na LinearLayout pionowy z tłem #F0F4F8 i android:id="@+id/main".
  3. Dodaj tytuł „Profil ucznia”: 30sp, pogrubiony, biały, tło #0B6E6E, padding 16dp, na całą szerokość.
  4. Dodaj trzy napisy 18sp z marginesem lewym 16dp i górnym 16dp / 8dp / 8dp. Ostatni zapisz kursywą.
  5. Dodaj podpis „Autor: …” (wpisz swój numer): szary #808080, 14sp, wyśrodkowany, margines górny 24dp.
  6. Uruchom i porównaj z makietą.

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Każdy napis to osobny TextView. Wszystkie leżą bezpośrednio w jednym pionowym LinearLayout.

Poziom 2 — konkretna wskazówka

Margines lewy to android:layout_marginStart="16dp", górny android:layout_marginTop="…dp". Kursywa: android:textStyle="italic".

Poziom 3 — pseudokod / struktura

Struktura:

⏱ ok. 40 min

DANECo wpisuje / wybiera użytkownik?
ZDARZENIACo uruchamia działania?

WYNIKCo aplikacja wyświetla lub zmienia?

  • Napis „Schronisko Łapa”.
  • Napis „Godziny otwarcia:”.
  • Napisy „pon.–pt. 10:00–18:00” oraz „sobota 10:00–14:00”.
  • Napis „Adopcje: tel. 123 456 789”.
  • Napis „Autor: ”, dalej wstawiony numer zdającego.

Założenia aplikacji:

  • Interfejs użytkownika zapisany w języku znaczników (XML), rozkład liniowy pionowy.
  • Tło strony Cornsilk (#FFF8DC).

  • Napis „Godziny otwarcia:” pogrubiony; napisy z godzinami mają lewy margines 10.

  • Kod aplikacji przygotuj tak jak na egzaminie: zrzut ekranu mobile1.png (emulator + środowisko), archiwum mobilna.zip, kopie activity_main.xml i MainActivity.java w folderze mobilna.
