Bloki › Blok 2

Blok 2. Przycisk → zmiana stanu → interfejs

Faza I — wyrównanie W trakcie

Obsługujesz kliknięcie przycisku, przechowujesz stan aplikacji w polu klasy (licznik, suma) i odświeżasz napisy. Budujesz rząd przycisków o równej szerokości.

1. Cel

Po wykonaniu tego bloku będziesz potrafił:

  • pobrać kontrolkę z XML do Javy przez findViewById i obsłużyć kliknięcie setOnClickListener,
  • przechowywać stan aplikacji w polu klasy (licznik, suma) i ograniczać go (np. „nie mniej niż 0”),
  • składać napis z tekstu i liczby i wyświetlać go przez setText,
  • ułożyć przyciski obok siebie w poziomym LinearLayout z layout_weight i ustawić ich kolor (backgroundTint).

2. Krótkie przypomnienie

Schemat, który powtarza się w każdym arkuszu

Tekst
kliknięcie przycisku  →  zmiana pola klasy (stanu)  →  setText(...) na ekranie

Trzy kroki w Javie

Java
public class MainActivity extends AppCompatActivity {

    private int licznik = 0;          // 1. stan: POLE klasy, nie zmienna w onCreate
    private TextView tvLicznik;       //    kontrolki, których używasz w wielu miejscach

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        tvLicznik = findViewById(R.id.tvLicznik);        // 2. połączenie z XML (to samo id!)
        Button btnPolub = findViewById(R.id.btnPolub);

        btnPolub.setOnClickListener(v -> {               // 3. obsługa zdarzenia
            licznik++;
            tvLicznik.setText(licznik + " polubień");    //    liczba + tekst = tekst
        });
    }
}

Importy dopisze Android Studio: kliknij czerwoną nazwę klasy i naciśnij Alt+Enter (android.widget.Button, android.widget.TextView).

tvLicznik.setText(licznik); — kompiluje się, ale zamyka aplikację (Resources$NotFoundException): liczba jest traktowana jak identyfikator zasobu. Zawsze składaj napis: setText(licznik + " polubień") lub setText(String.valueOf(licznik)).

Ta sama obsługa w stylu z arkuszy (klasa anonimowa)

W pomocach z arkuszy spotkasz zapis bez strzałki ->. Działa identycznie:

Java
btnPolub.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        licznik++;
        tvLicznik.setText(licznik + " polubień");
    }
});

W nowych projektach (motyw Material 3) atrybut android:background na przycisku nie zmienia koloru. Używaj android:backgroundTint="#…". Na napisach (TextView) i rozkładach background działa normalnie.

Ćwiczenie natychmiastowe: w przykładzie poniżej dopisz drugi przycisk „ZERUJ”, który ustawia licznik na 0.

3. Przykład

Najmniejsza aplikacja ze zdarzeniem: licznik kliknięć. Zwróć uwagę na komentarze 1 i 2 w kodzie — ta kolejność (stan → ekran) będzie się powtarzać we wszystkich blokach.

package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    // stan aplikacji — pole klasy (żyje tak długo jak ekran)
    private int licznik = 0;
    private TextView tvLicznik;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        tvLicznik = findViewById(R.id.tvLicznik);
        Button btnKliknij = findViewById(R.id.btnKliknij);

        btnKliknij.setOnClickListener(v -> {
            licznik++;                                   // 1. zmiana stanu
            tvLicznik.setText("Kliknięcia: " + licznik); // 2. aktualizacja interfejsu
        });
    }
}

4. Mikroćwiczenia

Ćwiczenie 2.1 — Połącz XML z Javą

W XML jest <TextView android:id="@+id/tvWynik" … />. Zadeklaruj pole klasy i przypisz je w onCreate.

Sprawdź odpowiedź
Java
private TextView tvWynik;          // pole klasy (nad onCreate)
...
tvWynik = findViewById(R.id.tvWynik);   // w onCreate, PO setContentView

findViewById przed setContentView zwraca null — aplikacja się zamknie przy pierwszym setText.

Ćwiczenie 2.2 — Co się stanie?

Java
int punkty = 5;
tvPunkty.setText(punkty);

Aplikacja się kompiluje. Co się dzieje po kliknięciu? Jak to poprawić?

Sprawdź odpowiedź

Awaria android.content.res.Resources$NotFoundException: String resource ID #0x5. Poprawnie: tvPunkty.setText("Punkty: " + punkty); albo tvPunkty.setText(String.valueOf(punkty));.

Ćwiczenie 2.3 — Licznik nie może być ujemny

Uzupełnij obsługę przycisku USUŃ tak, aby licznik malał, ale nigdy nie spadł poniżej 0 (wymaganie z Arkusza_02). Napis ma postać „<x> polubień”.

Sprawdź odpowiedź
Java
btnUsun.setOnClickListener(v -> {
    if (licznik > 0) {
        licznik--;
    }
    tvLicznik.setText(licznik + " polubień");
});

Ćwiczenie 2.4 — Przewidź wynik

Licznik startuje od 0. Przyciski: POLUB (+1), USUŃ (−1, nie poniżej 0). Kolejność kliknięć: POLUB, POLUB, USUŃ, USUŃ, USUŃ, POLUB. Co pokazuje napis?

Sprawdź odpowiedź

„1 polubień”. Trzecie USUŃ nie zmienia licznika (już 0), ostatnie POLUB daje 1.

Ćwiczenie 2.5 — Trzy przyciski — równa szerokość

Napisz XML rzędu z trzema przyciskami „POLUB”, „USUŃ”, „ZAPISZ”, które razem wypełniają szerokość ekranu po równo.

Sprawdź odpowiedź

Poziomy LinearLayout (match_parent), a w nim trzy przyciski z layout_width="0dp" i layout_weight="1". Szerokość 0dp mówi: „nie licz szerokości z treści, podziel wolne miejsce według wag”.

Ćwiczenie 2.6 — Z lambdy na klasę anonimową

Przepisz btnReset.setOnClickListener(v -> { licznik = 0; pokaz(); }); na zapis z new View.OnClickListener().

Sprawdź odpowiedź
Java
btnReset.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        licznik = 0;
        pokaz();
    }
});

Potrzebny import android.view.View.

5. Zadanie prowadzone

Rozmiar tekstu: A− / A+

⏱ ok. 40 min

Przyciski zmieniają rozmiar czcionki tekstu w krokach co 2 (w zakresie 12–40). Stan to jedna liczba, ale od niej zależą dwie rzeczy: napis „Rozmiar: …” i wygląd innej kontrolki. Kod budujesz krok po kroku; każdy krok kończ uruchomieniem.

Działanie:

  • „A+” zwiększa rozmiar o 2, ale nie powyżej 40.
  • „A−” zmniejsza rozmiar o 2, ale nie poniżej 12.
  • „DOMYŚLNY” ustawia 20.
  • Po każdej zmianie: napis „Rozmiar: <liczba>” oraz rozmiar czcionki tekstu na dole ekranu (setTextSize(rozmiar)).

Kroki:

  1. XML: tytuł (tło #1D4F91, biały, 28sp), poziomy rozkład z przyciskami „A−” i „A+” (wagi 1:1, backgroundTint="#1D4F91"), napis rozmiaru (wyśrodkowany), przycisk DOMYŚLNY (szary #808080, wyśrodkowany), tekst próbny 20sp.
  2. Java: pola rozmiar, tvRozmiar, tvTekst; stałe MINIMUM = 12, MAKSIMUM = 40, DOMYSLNY = 20, KROK = 2.
  3. Trzy obsługi kliknięcia.
  4. Wspólna metoda aktualizujEkran() — wywołuj ją na końcu każdej obsługi, żeby nie powtarzać kodu.

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Najpierw ustal, który element jest w którym rozkładzie. Przyciski A− i A+ muszą być w zagnieżdżonym poziomym rozkładzie, DOMYŚLNY — już nie.

Poziom 2 — konkretna wskazówka

Warunki: przy A+ if (rozmiar + KROK <= MAKSIMUM) rozmiar += KROK;, przy A− if (rozmiar - KROK >= MINIMUM) rozmiar -= KROK;. Zmiana czcionki: tvTekst.setTextSize(rozmiar);.

Poziom 3 — pseudokod / struktura
Tekst
pola: rozmiar = 20, tvRozmiar, tvTekst; stałe 12, 40, 20, 2
onCreate:
    znajdź kontrolki
    A+  → jeśli rozmiar + 2 <= 40: rozmiar += 2; aktualizujEkran()
    A−  → jeśli rozmiar − 2 >= 12: rozmiar −= 2; aktualizujEkran()
    DOMYŚLNY → rozmiar = 20; aktualizujEkran()
aktualizujEkran():
    tvRozmiar ← "Rozmiar: " + rozmiar
    tvTekst.setTextSize(rozmiar)
Poziom 4 — fragment implementacji
Java
private void aktualizujEkran() {
    tvRozmiar.setText("Rozmiar: " + rozmiar);
    tvTekst.setTextSize(rozmiar);
}

package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private static final int MINIMUM = 12;
    private static final int MAKSIMUM = 40;
    private static final int DOMYSLNY = 20;
    private static final int KROK = 2;

    private int rozmiar = DOMYSLNY;
    private TextView tvRozmiar;
    private TextView tvTekst;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        tvRozmiar = findViewById(R.id.tvRozmiar);
        tvTekst = findViewById(R.id.tvTekst);
        Button btnMniejsza = findViewById(R.id.btnMniejsza);
        Button btnWieksza = findViewById(R.id.btnWieksza);
        Button btnDomyslny = findViewById(R.id.btnDomyslny);

        btnWieksza.setOnClickListener(v -> {
            if (rozmiar + KROK <= MAKSIMUM) {
                rozmiar += KROK;
            }
            aktualizujEkran();
        });

        btnMniejsza.setOnClickListener(v -> {
            if (rozmiar - KROK >= MINIMUM) {
                rozmiar -= KROK;
            }
            aktualizujEkran();
        });

        btnDomyslny.setOnClickListener(v -> {
            rozmiar = DOMYSLNY;
            aktualizujEkran();
        });
    }

    private void aktualizujEkran() {
        tvRozmiar.setText("Rozmiar: " + rozmiar);
        tvTekst.setTextSize(rozmiar);   // stan zmienia nie tylko napis, ale też wygląd innej kontrolki
    }
}

6. Zadanie samodzielne

Kalorie przekąsek

⏱ ok. 35 min

Ten sam mechanizm (zdarzenie → stan → interfejs), ale inny problem: kilka przycisków dodaje różne wartości do jednej sumy.

  • JABŁKO dodaje 52 kcal, BATON 250 kcal, SOK 110 kcal. Każde kliknięcie zwiększa też liczbę zjedzonych przekąsek o 1.
  • Napisy: „Suma: <kcal> kcal” oraz „Zjedzone przekąski: <n>”.
  • WYZERUJ ustawia obie wartości na 0.
  • Tło ekranu #FFFDE7, przyciski w jednym rzędzie o równej szerokości z marginesem 4dp, każdy w innym kolorze (dowolnym).
  • Nie powtarzaj kodu trzy razy — napisz metodę dodaj(int kcal).

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Wszystkie trzy przyciski robią to samo, różni się tylko liczba kalorii. To sygnał, że potrzebna jest metoda z parametrem.

Poziom 2 — konkretna wskazówka

btnJablko.setOnClickListener(v -> dodaj(52)); — lambda może wywołać metodę w jednej linii.

Poziom 3 — pseudokod / struktura
Tekst
pola: sumaKcal = 0, liczbaPrzekasek = 0
dodaj(kcal): sumaKcal += kcal; liczbaPrzekasek++; pokaz()
pokaz(): ustaw oba napisy
WYZERUJ: oba pola = 0; pokaz()
Poziom 4 — fragment implementacji
Java
private void dodaj(int kcal) {
    sumaKcal += kcal;
    liczbaPrzekasek++;
    pokaz();
}

package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private int sumaKcal = 0;
    private int liczbaPrzekasek = 0;
    private TextView tvSuma;
    private TextView tvIle;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        tvSuma = findViewById(R.id.tvSuma);
        tvIle = findViewById(R.id.tvIle);
        Button btnJablko = findViewById(R.id.btnJablko);
        Button btnBaton = findViewById(R.id.btnBaton);
        Button btnSok = findViewById(R.id.btnSok);
        Button btnWyzeruj = findViewById(R.id.btnWyzeruj);

        btnJablko.setOnClickListener(v -> dodaj(52));
        btnBaton.setOnClickListener(v -> dodaj(250));
        btnSok.setOnClickListener(v -> dodaj(110));
        btnWyzeruj.setOnClickListener(v -> {
            sumaKcal = 0;
            liczbaPrzekasek = 0;
            pokaz();
        });
    }

    private void dodaj(int kcal) {
        sumaKcal += kcal;
        liczbaPrzekasek++;
        pokaz();
    }

    private void pokaz() {
        tvSuma.setText("Suma: " + sumaKcal + " kcal");
        tvIle.setText("Zjedzone przekąski: " + liczbaPrzekasek);
    }
}

7. Zadanie w stylu INF.04

Licznik szklanek wody

⏱ ok. 45 min

Wykonaj aplikację mobilną pomagającą kontrolować liczbę wypitych szklanek wody i uruchom ją w emulatorze.

Krok 1–6: analiza polecenia. Zanim otworzysz Android Studio, wypisz na kartce (lub w komentarzu) odpowiedzi:
INTERFEJSCo musi znaleźć się na ekranie?
DANECo wpisuje / wybiera użytkownik?
ZDARZENIACo uruchamia działania?
LOGIKACo trzeba policzyć / sprawdzić / zmienić?
WYNIKCo aplikacja wyświetla lub zmienia?
WYGLĄDKolory, rozmiary, marginesy, rozkłady?
Porównaj swoją analizę z wzorcową
INTERFEJStytuł, napis celu, napis licznika, 2 przyciski w rzędzie, przycisk RESET, obszar komunikatów
DANEbrak pól — tylko przyciski
ZDARZENIAkliknięcie „+ SZKLANKA”, „− SZKLANKA”, „RESET”
LOGIKAlicznik 0..12 (nie mniej niż 0, nie więcej niż 12); porównanie z celem 8
WYNIK„<x> / 8 szklanek”; komunikat: „Zostało: <n>” / „Cel osiągnięty!” / „Licznik wyzerowany”; na starcie „Autor: <numer>”
WYGLĄDtło #E1F5FE; tytuł #0277BD biały, największy; licznik pogrubiony; przyciski #0277BD w rzędzie po równo; RESET #9E9E9E wyśrodkowany

Elementy aplikacji:

  • Napis „Nawodnienie”.
  • Napis „Cel: 8 szklanek dziennie”.
  • Napis licznika w postaci „<x> / 8 szklanek”, w stanie początkowym „0 / 8 szklanek”.
  • Dwa przyciski obok siebie: „+ SZKLANKA” i „− SZKLANKA”.
  • Przycisk „RESET”.
  • Obszar komunikatów; na początku działania aplikacji wyświetla „Autor: ”, dalej numer zdającego.

Działanie aplikacji:

  • „+ SZKLANKA” zwiększa licznik o 1; licznik nie może przekroczyć 12.
  • „− SZKLANKA” zmniejsza licznik o 1; licznik nie może być niższy niż 0.
  • Po każdej zmianie licznika w obszarze komunikatów wyświetla się „Zostało: <n>”, gdzie n = 8 − licznik, albo „Cel osiągnięty!”, gdy licznik wynosi co najmniej 8.
  • „RESET” ustawia licznik na 0, a w obszarze komunikatów wyświetla „Licznik wyzerowany”.

Założenia aplikacji:

  • Interfejs w XML; rozkład liniowy pionowy z zagnieżdżonym rozkładem poziomym dla przycisków „+” i „−”.
  • Tło strony LightCyan (#E1F5FE). Tytuł: tło #0277BD, biała czcionka, rozmiar największy w aplikacji, marginesy wewnętrzne 10.
  • Przyciski „+” i „−” mają kolor tła #0277BD, białą czcionkę i razem wypełniają szerokość rozkładu. Przycisk RESET: tło #9E9E9E, wyśrodkowany.
  • Napis licznika pogrubiony i wyśrodkowany. Obszar komunikatów wyśrodkowany.
  • Wartości 8 i 12 zapisz w kodzie jako stałe o znaczących nazwach.

Poziom 3 — pseudokod / struktura
Tekst
+   : jeśli licznik < MAKSIMUM → licznik++ ; pokazStan()
−   : jeśli licznik > 0        → licznik-- ; pokazStan()

java/com/example/egzamin/MainActivity.java
package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private static final int CEL = 8;
    private static final int MAKSIMUM = 12;

    private int liczbaSzklanek = 0;
    private TextView tvLicznik;
    private TextView tvKomunikat;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        tvLicznik = findViewById(R.id.tvLicznik);
        tvKomunikat = findViewById(R.id.tvKomunikat);
        Button btnDodaj = findViewById(R.id.btnDodaj);
        Button btnOdejmij = findViewById(R.id.btnOdejmij);
        Button btnReset = findViewById(R.id.btnReset);

        btnDodaj.setOnClickListener(v -> {
            if (liczbaSzklanek < MAKSIMUM) {
                liczbaSzklanek++;
            }
            pokazStan();
        });

        btnOdejmij.setOnClickListener(v -> {
            if (liczbaSzklanek > 0) {
                liczbaSzklanek--;
            }
            pokazStan();
        });

        btnReset.setOnClickListener(v -> {
            liczbaSzklanek = 0;
            tvLicznik.setText("0 / " + CEL + " szklanek");
            tvKomunikat.setText("Licznik wyzerowany");
        });
    }

    private void pokazStan() {
        tvLicznik.setText(liczbaSzklanek + " / " + CEL + " szklanek");
        if (liczbaSzklanek >= CEL) {
            tvKomunikat.setText("Cel osiągnięty!");
        } else {
            tvKomunikat.setText("Zostało: " + (CEL - liczbaSzklanek));
        }
    }
}
