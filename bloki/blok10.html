Blok 10. Losowanie, tablice i algorytmy w aplikacji

Faza II — łączenie umiejętności W trakcie

Losujesz liczby, zapisujesz je w tablicy, liczysz punkty algorytmem zliczania wystąpień i pokazujesz wyniki jako obrazy. Logikę trzymasz w metodach niezależnych od interfejsu — tak jak w części konsolowej egzaminu.

1. Cel

Po wykonaniu tego bloku będziesz potrafił:

  • losować liczby całkowite z zadanego zakresu (Random.nextInt),
  • zapisywać wyniki w tablicy i obsługiwać kilka kontrolek przez tablicę kontrolek i pętlę,
  • liczyć punkty algorytmem zliczania wystąpień (tablica liczników) i zwracać wynik z metody,
  • zamieniać wartości na obrazy przez tablicę R.drawable (wartość → indeks),
  • resetować stan gry (liczniki, obrazy, napisy, dostępność przycisku).

2. Krótkie przypomnienie

Losowanie

Java
import java.util.Random;
private final Random losowanie = new Random();   // pole — jedno na aplikację

int kosc = losowanie.nextInt(6) + 1;   // nextInt(6) → 0..5, więc +1 → 1..6
int indeks = losowanie.nextInt(4);     // 0..3 — gotowy indeks tablicy

nextInt(6) bez +1 daje wartości 0..5 — kość z „zerem” i przesunięte obrazy.

Wartość → obraz

Java
private final int[] obrazyKosci = {R.drawable.kosc1, R.drawable.kosc2, R.drawable.kosc3,
                                   R.drawable.kosc4, R.drawable.kosc5, R.drawable.kosc6};
ivKosc.setImageResource(obrazyKosci[wartosc - 1]);   // wartość 1 → indeks 0

Tablica kontrolek i pętla (5 obrazów z Arkusza_12)

Java
ImageView[] kosci = {findViewById(R.id.iv1), findViewById(R.id.iv2), findViewById(R.id.iv3),
                     findViewById(R.id.iv4), findViewById(R.id.iv5)};
for (int i = 0; i < kosci.length; i++) {
    kosci[i].setImageResource(obrazyKosci[wyniki[i] - 1]);
}

Zliczanie wystąpień

Java
int[] ile = new int[7];              // indeksy 1..6 dla oczek (0 nieużywany)
for (int w : wyniki) {
    ile[w]++;                        // ile[2] = ile razy wypadła dwójka
}

Z tablicy liczników łatwo policzyć: „wartość wypadła co najmniej 2 razy”, „wszystkie takie same”, „największa liczba powtórzeń”.

Logika bez interfejsu

Metody liczące nie dotykają kontrolek — dostają tablicę, zwracają liczbę. Tak samo jak w części konsolowej (i można je stamtąd skopiować):

Java
private int policzPunkty(int[] wyniki) { … return suma; }

Ćwiczenie natychmiastowe: w przykładzie wykonaj 20 rzutów i sprawdź, czy liczby orłów i reszek są „podobne”. Zmień nextInt(2) na nextInt(3) — co się stanie z kodem if/else?

package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.ImageView;
import android.widget.TextView;

import java.util.Random;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private final Random losowanie = new Random();   // jeden obiekt na całą aplikację
    private int orly = 0;
    private int reszki = 0;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        ImageView ivMoneta = findViewById(R.id.ivMoneta);
        TextView tvWynik = findViewById(R.id.tvWynik);
        Button btnRzuc = findViewById(R.id.btnRzuc);

        btnRzuc.setOnClickListener(v -> {
            int rzut = losowanie.nextInt(2);   // 0 lub 1
            if (rzut == 0) {
                orly++;
                ivMoneta.setImageResource(R.drawable.moneta_orzel);
            } else {
                reszki++;
                ivMoneta.setImageResource(R.drawable.moneta_reszka);
            }
            tvWynik.setText("Orły: " + orly + ", reszki: " + reszki);
        });
    }
}

4. Mikroćwiczenia

Ćwiczenie 10.1 — Zakresy

Zapisz losowanie: a) liczby 1–49, b) indeksu tablicy o długości n, c) liczby od −5 do 5.

Sprawdź odpowiedź

a) losowanie.nextInt(49) + 1; b) losowanie.nextInt(n); c) losowanie.nextInt(11) - 5 (11 wartości).

Ćwiczenie 10.2 — Punkty jak w Arkuszu_12

Napisz metodę int policzPunkty(int[] wyniki): punkty to suma oczek tych wartości, które wypadły co najmniej 2 razy. Test: {1, 5, 2, 2, 5} → 14; {2, 1, 2, 3, 2} → 6.

Sprawdź odpowiedź
Java
private int policzPunkty(int[] wyniki) {
    int[] ile = new int[7];
    for (int w : wyniki) {
        ile[w]++;
    }
    int suma = 0;
    for (int oczka = 1; oczka <= 6; oczka++) {
        if (ile[oczka] >= 2) {
            suma += oczka * ile[oczka];
        }
    }
    return suma;
}

{1,5,2,2,5}: 2·2 + 5·2 = 14. {2,1,2,3,2}: 2·3 = 6.

Ćwiczenie 10.3 — Obraz kości

Wylosowano wartosc = 6, tablica obrazyKosci ma 6 elementów. Który zapis jest poprawny: obrazyKosci[wartosc] czy obrazyKosci[wartosc - 1]? Co zrobi błędny?

Sprawdź odpowiedź

obrazyKosci[wartosc - 1]. Wersja bez -1 dla szóstki rzuci ArrayIndexOutOfBoundsException (indeks 6 w tablicy 0..5), a dla pozostałych pokaże złą ściankę.

Ćwiczenie 10.4 — Bez powtórzeń

Opisz słowami (pseudokod), jak wylosować 6 różnych liczb z 1–49 (desktop/konsola Arkusza_15).

Sprawdź odpowiedź

Dopóki nie masz 6 liczb: wylosuj kandydata; jeśli nie ma go w dotychczasowych wynikach — dopisz. (Kod w zadaniu prowadzonym: losujBezPowtorzen.)

Ćwiczenie 10.5 — Reset

Arkusz_12: „RESETUJ WYNIK” → pięć obrazów question, wynik gry 0, oba napisy wyników 0. Napisz treść metody resetuj() przy tablicy kosci i polu wynikGry.

Sprawdź odpowiedź
Java
private void resetuj() {
    wynikGry = 0;
    for (ImageView k : kosci) {
        k.setImageResource(R.drawable.question);
    }
    tvWynikLosowania.setText("Wynik tego losowania: 0");
    tvWynikGry.setText("Wynik gry: 0");
}

5. Zadanie prowadzone

Mini Lotto 3 z 20

⏱ ok. 35 min

Losowanie bez powtórzeń, tablica kontrolek obsługiwana pętlą i dwie metody statystyk. Logika w osobnych metodach — interfejs tylko wywołuje je i pokazuje wyniki.

Działanie: LOSUJ losuje 3 różne liczby z 1–20 i wpisuje je do trzech pól. Pod spodem: „Suma: <s>, największa: <m>”.

Kroki:

  1. XML: tytuł, rząd trzech TextView (waga 1, tło #F9A825, 26sp, start „?”), przycisk, napis statystyki.
  2. Java: TextView[] pola z trzech findViewById.
  3. Metody: losujBezPowtorzen(int ile, int zakres), zawiera(int[] t, int ileElementow, int x), suma(int[]), maksimum(int[]).
  4. LOSUJ: wynik do tablicy, pętla wpisująca liczby do pól, napis statystyki.
  5. Test: kliknij 20 razy — nigdy nie pojawią się dwie takie same liczby.

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Najpierw napisz i sprawdź losujBezPowtorzen — pętla while działa, dopóki nie zbierzesz wymaganej liczby różnych wartości.

Poziom 2 — konkretna wskazówka

zawiera sprawdza tylko elementy już wylosowane (od 0 do ileElementow - 1), bo reszta tablicy to zera.

Poziom 3 — pseudokod / struktura
Tekst
losujBezPowtorzen(ile, zakres):
    wynik ← tablica[ile]; n ← 0
    dopóki n < ile:
        k ← los(1..zakres)
        jeśli k nie występuje w wynik[0..n-1]: wynik[n] ← k; n++
    zwróć wynik
Poziom 4 — fragment implementacji
Java
private int[] losujBezPowtorzen(int ile, int zakres) {
    int[] wynik = new int[ile];
    int wylosowane = 0;
    while (wylosowane < ile) {
        int kandydat = losowanie.nextInt(zakres) + 1;
        if (!zawiera(wynik, wylosowane, kandydat)) {
            wynik[wylosowane] = kandydat;
            wylosowane++;
        }
    }
    return wynik;
}

package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.TextView;

import java.util.Random;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private static final int ILE_LICZB = 3;
    private static final int ZAKRES = 20;

    private final Random losowanie = new Random();
    private TextView[] pola;
    private TextView tvStatystyka;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        // tablica kontrolek — pozwala obsłużyć je w pętli
        pola = new TextView[]{findViewById(R.id.tvLiczba1), findViewById(R.id.tvLiczba2), findViewById(R.id.tvLiczba3)};
        tvStatystyka = findViewById(R.id.tvStatystyka);
        Button btnLosuj = findViewById(R.id.btnLosuj);

        btnLosuj.setOnClickListener(v -> {
            int[] liczby = losujBezPowtorzen(ILE_LICZB, ZAKRES);
            for (int i = 0; i < liczby.length; i++) {
                pola[i].setText(String.valueOf(liczby[i]));
            }
            tvStatystyka.setText("Suma: " + suma(liczby) + ", największa: " + maksimum(liczby));
        });
    }

    // logika bez interfejsu — łatwa do sprawdzenia i ponownego użycia
    private int[] losujBezPowtorzen(int ile, int zakres) {
        int[] wynik = new int[ile];
        int wylosowane = 0;
        while (wylosowane < ile) {
            int kandydat = losowanie.nextInt(zakres) + 1;   // 1..zakres
            if (!zawiera(wynik, wylosowane, kandydat)) {
                wynik[wylosowane] = kandydat;
                wylosowane++;
            }
        }
        return wynik;
    }

    private boolean zawiera(int[] tablica, int ileElementow, int wartosc) {
        for (int i = 0; i < ileElementow; i++) {
            if (tablica[i] == wartosc) {
                return true;
            }
        }
        return false;
    }

    private int suma(int[] tablica) {
        int s = 0;
        for (int x : tablica) {
            s += x;
        }
        return s;
    }

    private int maksimum(int[] tablica) {
        int max = tablica[0];
        for (int x : tablica) {
            if (x > max) {
                max = x;
            }
        }
        return max;
    }
}

6. Zadanie samodzielne

Kamień, papier, nożyce

⏱ ok. 30 min

Wybór gracza (przycisk) kontra losowy wybór komputera; obrazy z tablicy, wynik rundy i wynik gry.

  • Kodowanie ruchów: 0 — kamień, 1 — papier, 2 — nożyce (tablica obrazów w tej kolejności). Na starcie oba obrazy to pytajnik.
  • Kliknięcie przycisku: obraz gracza, losowy ruch komputera i jego obraz, komunikat rundy („Remis”, „Wygrywasz rundę!”, „Komputer wygrywa rundę”), aktualizacja „Gracz x : y Komputer”.
  • Zasady: papier bije kamień, nożyce biją papier, kamień bije nożyce. Spróbuj zapisać rozstrzygnięcie jednym wzorem, bez 9 przypadków if.

Zasoby do zadania

Pobierz wszystkie: zasoby_b10-samodzielne.zip. Obrazy skopiuj do app/src/main/res/drawable (nazwy: małe litery, bez spacji i myślników).

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Wszystkie trzy przyciski wywołują zagraj(ruchGracza).

Poziom 2 — konkretna wskazówka

Wzór: (gracz - komputer + 3) % 3 → 0 remis, 1 wygrywa gracz, 2 wygrywa komputer. Sprawdź na kartce wszystkie 9 par.

Tekst

    napis wyniku gry

package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.ImageView;
import android.widget.TextView;

import java.util.Random;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    // 0 = kamień, 1 = papier, 2 = nożyce
    private final int[] obrazy = {R.drawable.kamien, R.drawable.papier, R.drawable.nozyce};
    private final Random losowanie = new Random();
    private int punktyGracza = 0;
    private int punktyKomputera = 0;

    private ImageView ivGracz, ivKomputer;
    private TextView tvWynikGry, tvRunda;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        ivGracz = findViewById(R.id.ivGracz);
        ivKomputer = findViewById(R.id.ivKomputer);
        tvWynikGry = findViewById(R.id.tvWynikGry);
        tvRunda = findViewById(R.id.tvRunda);
        Button btnKamien = findViewById(R.id.btnKamien);
        Button btnPapier = findViewById(R.id.btnPapier);
        Button btnNozyce = findViewById(R.id.btnNozyce);

        btnKamien.setOnClickListener(v -> zagraj(0));
        btnPapier.setOnClickListener(v -> zagraj(1));
        btnNozyce.setOnClickListener(v -> zagraj(2));
    }

    private void zagraj(int gracz) {
        int komputer = losowanie.nextInt(3);
        ivGracz.setImageResource(obrazy[gracz]);
        ivKomputer.setImageResource(obrazy[komputer]);

        int roznica = (gracz - komputer + 3) % 3;   // 0 remis, 1 wygrywa gracz, 2 wygrywa komputer
        if (roznica == 0) {
            tvRunda.setText("Remis");
        } else if (roznica == 1) {
            punktyGracza++;
            tvRunda.setText("Wygrywasz rundę!");
        } else {
            punktyKomputera++;
            tvRunda.setText("Komputer wygrywa rundę");
        }
        tvWynikGry.setText("Gracz " + punktyGracza + " : " + punktyKomputera + " Komputer");
    }
}

  • Napis „Saldo: 100 żetonów”.

Działanie aplikacji:

  • Po wciśnięciu „ZAGRAJ”: saldo zmniejsza się o 10; dla każdego bębna losowany jest jeden z czterech symboli (wisnia, cytryna, dzwonek, siodemka) i wyświetlany jako obraz; obliczana jest wygrana i dodawana do salda.
  • Zasady wygranej: trzy siódemki — 200; trzy jednakowe inne symbole — 50; dokładnie dwa jednakowe symbole — 20; w pozostałych przypadkach — 0.

  • Jeżeli saldo jest mniejsze niż 10, przycisk „ZAGRAJ” staje się nieaktywny, a w napisie wygranej pojawia się „Koniec żetonów”.

  • Interfejs w XML; rozkład liniowy pionowy z zagnieżdżonym rozkładem poziomym dla trzech obrazów.

package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.ImageView;
import android.widget.TextView;

import java.util.Random;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private static final int SALDO_POCZATKOWE = 100;
    private static final int KOSZT_GRY = 10;
    private static final int SIODEMKA = 3;   // indeks symbolu 7

    // 0 = wiśnia, 1 = cytryna, 2 = dzwonek, 3 = siódemka
    private final int[] symbole = {R.drawable.wisnia, R.drawable.cytryna, R.drawable.dzwonek, R.drawable.siodemka};
    private final Random losowanie = new Random();
    private int saldo = SALDO_POCZATKOWE;

    private ImageView[] bebny;
    private TextView tvSaldo, tvWygrana;
    private Button btnZagraj;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        bebny = new ImageView[]{findViewById(R.id.ivBeben1), findViewById(R.id.ivBeben2), findViewById(R.id.ivBeben3)};
        tvSaldo = findViewById(R.id.tvSaldo);
        tvWygrana = findViewById(R.id.tvWygrana);
        btnZagraj = findViewById(R.id.btnZagraj);
        Button btnNowaGra = findViewById(R.id.btnNowaGra);

        btnZagraj.setOnClickListener(v -> zagraj());
        btnNowaGra.setOnClickListener(v -> nowaGra());
    }

    private void zagraj() {
        saldo -= KOSZT_GRY;
        int[] wynik = losujBebny();
        for (int i = 0; i < bebny.length; i++) {
            bebny[i].setImageResource(symbole[wynik[i]]);
        }
        int wygrana = policzWygrana(wynik);
        saldo += wygrana;
        tvWygrana.setText("Wygrana w tej rundzie: " + wygrana);
        tvSaldo.setText("Saldo: " + saldo + " żetonów");
        if (saldo < KOSZT_GRY) {
            btnZagraj.setEnabled(false);
            tvWygrana.setText("Koniec żetonów");
        }
    }

    private int[] losujBebny() {
        int[] wynik = new int[3];
        for (int i = 0; i < wynik.length; i++) {
            wynik[i] = losowanie.nextInt(symbole.length);   // 0..3
        }
        return wynik;
    }

    // zliczanie wystąpień: licznik[s] = ile razy wypadł symbol s
    private int policzWygrana(int[] wynik) {
        int[] licznik = new int[symbole.length];
        for (int s : wynik) {
            licznik[s]++;
        }
        int najwiecej = 0;
        for (int ile : licznik) {
            if (ile > najwiecej) {
                najwiecej = ile;
            }
        }
        if (licznik[SIODEMKA] == 3) {
            return 200;
        } else if (najwiecej == 3) {
            return 50;
        } else if (najwiecej == 2) {
            return 20;
        }
        return 0;
    }

    private void nowaGra() {
        saldo = SALDO_POCZATKOWE;
        for (ImageView beben : bebny) {
            beben.setImageResource(R.drawable.pytajnik);
        }
        tvSaldo.setText("Saldo: " + saldo + " żetonów");
        tvWygrana.setText("Wygrana w tej rundzie: 0");
        btnZagraj.setEnabled(true);
    }
}
