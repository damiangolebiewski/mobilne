Blok 5. Odtwarzanie wyglądu: rozkłady, marginesy, wagi

Faza II — łączenie umiejętności W trakcie

Zamieniasz zrzut ekranu i opis z arkusza na drzewo rozkładów: pion, poziom, zagnieżdżenia, wagi, marginesy, wyrównanie, linie. Ten blok przygotowuje do punktów za „wygląd zgodny z obrazem”.

1. Cel

Po wykonaniu tego bloku będziesz potrafił:

  • rozpisać ekran ze zrzutu na drzewo: rozkład pionowy → zagnieżdżone rozkłady poziome/pionowe → kontrolki,
  • dzielić szerokość wagami (layout_weight), także w proporcjach innych niż 1:1,
  • rozróżniać gravity / layout_gravity oraz padding / layout_margin i stosować je zgodnie z opisem,
  • narysować linię poziomą, wyrównać tekst do prawej i odtworzyć kolory, rozmiary i odstępy z polecenia.

2. Krótkie przypomnienie

Od obrazka do drzewa (zawsze przed kodem)

  1. Patrz od góry do dołu — to kolejne dzieci pionowego rozkładu głównego.
  2. Gdzie kilka elementów stoi obok siebie → zagnieżdżony rozkład poziomy.
  3. Gdzie w takim rzędzie jest kolumna (np. obraz obok kilku napisów, Arkusz_13) → w poziomym rozkładzie jeszcze jeden pionowy.
  4. Dopiero potem kolory, rozmiary i odstępy.
Tekst
LinearLayout vertical                      ← cały ekran
 ├─ TextView (tytuł)
 ├─ LinearLayout horizontal               ← rząd
 │   ├─ ImageView (obraz)                 ← lewa część
 │   └─ LinearLayout vertical             ← prawa kolumna
 │       ├─ TextView  ├─ EditText  ├─ Button  └─ TextView
 └─ …

Ściąga wyglądu

Wymaganie w arkuszuZapis w XML
„elementy obok siebie wypełniają szerokość”rząd horizontal; dzieci layout_width="0dp" + layout_weight="1"
„kolumna dwa razy szersza”wagi 1 i 2
„margines wewnętrzny 10”android:padding="10dp"
„margines górny 20 dla strony”android:paddingTop="20dp" na rozkładzie głównym
„marginesy zewnętrzne 5”android:layout_margin="5dp"
„margines lewy, prawy i dolny 20, górny 0”layout_marginStart/End/Bottom="20dp", layout_marginTop="0dp"
„napis wyrównany do prawej”layout_width="match_parent" + gravity="end"
„przycisk wyśrodkowany”layout_gravity="center_horizontal"
„tekst przycisku wyśrodkowany i pogrubiony”gravity="center" (domyślnie) + textStyle="bold"
„tło pola edycyjnego SkyBlue, tekst i podpowiedź Navy” (Arkusz_13)na EditText: background="#87CEEB", textColor="#000080", textColorHint="#000080"
„linia horyzontalna, kolor Gray”<View android:layout_width="match_parent" android:layout_height="1dp" android:background="#808080" />
„czcionka największa / średnia”np. tytuł 30sp, średnia 20sp, reszta 14–16sp
wyśrodkowanie w pionie w rzędzielayout_gravity="center_vertical" na dziecku albo gravity="center_vertical" na rzędzie

gravity ustawiasz na rodzicu, aby ułożyć jego dzieci/treść; layout_gravity na dziecku, aby ułożyć je w rodzicu. W pionowym LinearLayout layout_gravity działa tylko w poziomie (lewo / środek / prawo).

Ćwiczenie natychmiastowe: przerysuj na kartce drzewo ekranu z zadania INF.04 tego bloku (makieta niżej), zanim zobaczysz jakikolwiek kod.

4. Mikroćwiczenia

Ćwiczenie 5.1 — Makieta → drzewo (1)

Zaplanuj drzewo rozkładów (bez atrybutów) dla ekranu:

Sprawdź odpowiedź
Tekst
LinearLayout vertical
 ├─ TextView "Urządzenia" (match_parent, gravity center)
 ├─ LinearLayout horizontal
 │   ├─ ImageView (lampa)
 │   └─ LinearLayout vertical (width 0dp, weight 1)
 │       ├─ TextView "Lampa"  ├─ EditText  ├─ Button  └─ TextView
 └─ LinearLayout horizontal
     ├─ ImageView (głośnik)
     └─ LinearLayout vertical (width 0dp, weight 1)
         ├─ TextView "Głośnik" ├─ Button  └─ TextView

To dokładnie struktura z Arkusza_13 (pralka i odkurzacz).

Ćwiczenie 5.2 — Makieta → drzewo (2)

Zaplanuj drzewo dla ekranu z polem i przyciskiem w jednym rzędzie oraz listą pod spodem (jak Arkusz_05). Które elementy dostają wagę?

Sprawdź odpowiedź

Pionowy rozkład → poziomy rząd [EditText (0dp, weight 1) + Button (wrap_content)] → ListView (match_parent). Wagę dostaje tylko pole — przycisk ma szerokość swojego tekstu, a pole zajmuje resztę.

Ćwiczenie 5.3 — Proporcje

Rząd zawiera TextView „Ile ma lat?”, TextView „0” i SeekBar. Suwak ma zająć całą pozostałą szerokość. Jakie szerokości i wagi ustawisz?

Sprawdź odpowiedź

Oba napisy: wrap_content (bez wagi); suwak: layout_width="0dp" + layout_weight="1". Tak rozwiązuje się rząd wieku z Arkusza_10.

Ćwiczenie 5.4 — Marginesy z polecenia

Zapisz atrybuty: „Dla obrazów marginesy lewy, prawy i dolny 20, górny 0; wysokość obrazu 150” (Arkusz_13).

Sprawdź odpowiedź
XML
android:layout_height="150dp"
android:layout_marginStart="20dp"
android:layout_marginEnd="20dp"
android:layout_marginBottom="20dp"
android:layout_marginTop="0dp"

Ćwiczenie 5.5 — Co jest źle?

Napis ma layout_width="wrap_content" i gravity="end", ale nie jest przy prawej krawędzi. Dlaczego? Podaj dwa sposoby naprawy.

Sprawdź odpowiedź

Element jest tak wąski jak tekst, więc wyrównanie treści w nim nic nie zmienia. Naprawa: layout_width="match_parent" + gravity="end" albo layout_gravity="end" (przesunięcie całego elementu).

5. Zadanie prowadzone

Karta kontaktu

⏱ ok. 35 min

Odtwórz kartę kontaktu z makiety. Zawiera trzy poziomy zagnieżdżenia: rząd, w nim kolumnę i etykietę statusu. Przyciski zapisują ostatnią akcję — to utrwala obsługę kliknięć z bloku 2.

Kroki:

  1. Narysuj drzewo (pion → rząd [kolumna + status] → linia → rząd przycisków → notatka → ostatnia akcja).
  2. Rząd górny: kolumna z imieniem i stanowiskiem (waga 2), etykieta „ONLINE” (waga 1, tło #2E7D32, biały pogrubiony tekst, wyśrodkowana w pionie).
  3. Linia: View 1dp, #BDBDBD, marginesy boczne 12dp.
  4. Rząd trzech przycisków (#455A64) z odstępami 4dp między nimi.
  5. „Notatka” pogrubiona, opis szary, na dole napis kursywą wyrównany do prawej.
  6. Java: każdy przycisk wywołuje zapiszAkcje("…"), która ustawia „Ostatnia akcja: …”.

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

Status „ONLINE” ma być wyśrodkowany w pionie względem dwóch napisów obok — to rola layout_gravity="center_vertical" na dziecku poziomego rzędu.

Poziom 2 — konkretna wskazówka

Kolumna po lewej to LinearLayout pionowy z layout_width="0dp" i layout_weight="2"; status: 0dp i waga 1.

Poziom 3 — pseudokod / struktura
Tekst

 ├─ tvTytul
 ├─ LinearLayout horizontal (margin 12dp)
 │   ├─ LinearLayout vertical (0dp, weight 2) ─ tvNazwisko, tvStanowisko
 │   └─ tvStatus (0dp, weight 1, center_vertical, tło #2E7D32)
 ├─ View (1dp, #BDBDBD)
 ├─ LinearLayout horizontal ─ 3 × Button (0dp, weight 1)
 ├─ tvNotatkaTytul, tvNotatka

package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private TextView tvOstatnia;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        tvOstatnia = findViewById(R.id.tvOstatnia);
        Button btnZadzwon = findViewById(R.id.btnZadzwon);
        Button btnSms = findViewById(R.id.btnSms);
        Button btnEmail = findViewById(R.id.btnEmail);

        btnZadzwon.setOnClickListener(v -> zapiszAkcje("połączenie"));
        btnSms.setOnClickListener(v -> zapiszAkcje("SMS"));
        btnEmail.setOnClickListener(v -> zapiszAkcje("e-mail"));
    }

    private void zapiszAkcje(String akcja) {
        tvOstatnia.setText("Ostatnia akcja: " + akcja);
    }
}

6. Zadanie samodzielne

Nagłówek artykułu z oceną

⏱ ok. 35 min

Odtwórz nagłówek artykułu. Wymaga dwóch różnych technik wyrównania do prawej i rzędu, w którym przyciski mają szerokość tekstu, a napis zajmuje resztę.

  • Autor artykułu po lewej (#1D4F91), data po prawej (#808080) w jednym rzędzie.
  • Linia pozioma 2dp w kolorze #1D4F91, odstęp 10dp nad i pod linią.
  • Rząd dolny: przyciski „PRZYDATNE” (#2E7D32) i „NIE” (#C62828) o szerokości tekstu, napis oceny pogrubiony, dosunięty do prawej, elementy wyśrodkowane w pionie.
  • „PRZYDATNE” zwiększa ocenę o 1, „NIE” zmniejsza o 1 (ocena może być ujemna). Format: „Ocena: +2”, „Ocena: 0”, „Ocena: -1”.

Pomoc — otwieraj po kolei i tylko wtedy, gdy utkniesz:

Poziom 1 — kierunek

W górnym rzędzie oba napisy mogą mieć wagę 1 — wtedy dla daty wystarczy gravity="end". W dolnym rzędzie wagę dostaje tylko napis oceny.

Poziom 2 — konkretna wskazówka

Wyśrodkowanie w pionie wszystkich dzieci rzędu: android:gravity="center_vertical" na rzędzie. Znak plus: String znak = ocena > 0 ? "+" : "";.

Poziom 3 — pseudokod / struktura
Tekst
rząd dolny (horizontal, gravity center_vertical):
    Button PRZYDATNE (wrap_content, marginEnd 8dp)
    Button NIE       (wrap_content)
    TextView ocena   (0dp, weight 1, gravity end, bold)
zmienOcene(zmiana): ocena += zmiana; napis "Ocena: " + znak + ocena
Poziom 4 — fragment implementacji
Java
private void zmienOcene(int zmiana) {
    ocena += zmiana;
    String znak = ocena > 0 ? "+" : "";
    tvOcena.setText("Ocena: " + znak + ocena);
}

    private int ocena = 0;
    private TextView tvOcena;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        tvOcena = findViewById(R.id.tvOcena);
        Button btnPrzydatne = findViewById(R.id.btnPrzydatne);
        Button btnNieprzydatne = findViewById(R.id.btnNieprzydatne);

        btnPrzydatne.setOnClickListener(v -> zmienOcene(1));
        btnNieprzydatne.setOnClickListener(v -> zmienOcene(-1));
    }

    private void zmienOcene(int zmiana) {
        ocena += zmiana;
        String znak = ocena > 0 ? "+" : "";   // liczby ujemne mają już znak „-”
        tvOcena.setText("Ocena: " + znak + ocena);
    }
}

Elementy aplikacji:

  • Napis „Mecz ligowy”.
  • Dwie kolumny obok siebie. Każda zawiera: nazwę drużyny („Orły” / „Sokoły”), napis z liczbą bramek (początkowo „0”), przycisk „+1”.
  • Linia horyzontalna.
  • Napis „Prowadzi: remis”.
  • Przycisk „NOWY MECZ”.
  • Napis „Autor: ”, dalej numer zdającego.

Działanie aplikacji:

  • Przycisk „+1” w kolumnie zwiększa o 1 liczbę bramek danej drużyny.
  • Po każdej zmianie napis pod linią pokazuje „Prowadzi: <nazwa drużyny>” lub „Prowadzi: remis”.
  • „NOWY MECZ” zeruje oba wyniki i przywraca „Prowadzi: remis”.

Założenia aplikacji:

  • Interfejs w XML. Rozkład liniowy pionowy z zagnieżdżonym rozkładem poziomym, w którym są dwa rozkłady pionowe (kolumny).
  • Marginesy wewnętrzne całej strony 16, tło strony #F1F8E9.
  • Tytuł: tło #1B5E20, biała czcionka, rozmiar największy, tekst wyśrodkowany, marginesy wewnętrzne 10.
  • Kolumny mają równą szerokość, odstęp między nimi 16 (po 8 z każdej strony). Nazwy drużyn pogrubione, wszystkie napisy w kolumnach wyśrodkowane.
  • Przyciski „+1” na całą szerokość kolumny, tło #C62828 (Orły) i #1565C0 (Sokoły), biała czcionka.
  • Linia koloru Gray (#808080), wysokość 1, marginesy pionowe 16.
  • Przycisk „NOWY MECZ” wyśrodkowany, tło #424242. Napis z numerem zdającego wyrównany do prawej, mała szara czcionka.

package com.example.egzamin;

import android.os.Bundle;
import android.widget.Button;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    private int goleGospodarzy = 0;
    private int goleGosci = 0;
    private TextView tvWynikGospodarzy, tvWynikGosci, tvProwadzi;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        tvWynikGospodarzy = findViewById(R.id.tvWynikGospodarzy);
        tvWynikGosci = findViewById(R.id.tvWynikGosci);
        tvProwadzi = findViewById(R.id.tvProwadzi);
        Button btnGolGospodarzy = findViewById(R.id.btnGolGospodarzy);
        Button btnGolGosci = findViewById(R.id.btnGolGosci);
        Button btnNowyMecz = findViewById(R.id.btnNowyMecz);

        btnGolGospodarzy.setOnClickListener(v -> {
            goleGospodarzy++;
            odswiez();
        });
        btnGolGosci.setOnClickListener(v -> {
            goleGosci++;
            odswiez();
        });
        btnNowyMecz.setOnClickListener(v -> {
            goleGospodarzy = 0;
            goleGosci = 0;
            odswiez();
        });
    }

    private void odswiez() {
        tvWynikGospodarzy.setText(String.valueOf(goleGospodarzy));
        tvWynikGosci.setText(String.valueOf(goleGosci));
        if (goleGospodarzy > goleGosci) {
            tvProwadzi.setText("Prowadzi: Orły");
        } else if (goleGosci > goleGospodarzy) {
            tvProwadzi.setText("Prowadzi: Sokoły");
        } else {
            tvProwadzi.setText("Prowadzi: remis");
        }
    }
}
